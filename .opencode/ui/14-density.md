# 14 · 密度模式

## 1. 只有两档

| 档 | 代号 | 用途 |
|---|---|---|
| 标准 | `comfortable`（默认） | 设置页、表单、引导、对话框 |
| 紧凑 | `compact` | 数据表格、侧栏列表、工具栏、终端 |

**不给用户自由切换**。密度是界面职责的属性，不是偏好：表格就是紧凑，设置页就是标准。用户可选密度只会在同一屏里制造不一致。

## 2. 尺寸映射

| 元素 | 标准 | 紧凑 | 差值 |
|---|---|---|---|
| 控件高（按钮/输入） | 32 | 28 | −4 |
| 大控件 / 主按钮 | 36 | 32 | −4 |
| 行高（列表/表格） | 36 | 28 | −8 |
| 单元格内距（纵向） | 8 | 4 | −4 |
| 区块间距 | 16 | 12 | −4 |
| 分组间距 | 24 | 20 | −4 |
| 图标尺寸 | 16 | 16 | 0 |
| 图标与文字间距 | 6 | 4 | −2 |
| 圆角 | 12 | 8 | −4 |

**字号不变**。密度只压缩留白，不压缩字号——12→11 会让中文变糊，这是紧凑模式最常见的错误。

## 3. 三条守恒

紧凑化过程中以下三项**必须保持不变**：

1. **点击热区** ≥ 24×24。行高 28 时，图标按钮靠 padding 撑到 24。
2. **焦点环可见**。密度高时允许用 1px 环（上限），但不能取消。
3. **分隔线仍是 0.5px**，不因为空间紧就省掉，否则行边界靠猜。

## 4. 实现方式

用属性 + 变量覆盖，不要在组件里写两套类：

```css
:root {
  --density-control-h: 32px;
  --density-row-h: 36px;
  --density-cell-y: 8px;
  --density-gap: 16px;
  --density-radius: 12px;
}

[data-density="compact"] {
  --density-control-h: 28px;
  --density-row-h: 28px;
  --density-cell-y: 4px;
  --density-gap: 12px;
  --density-radius: 8px;
}

.row {
  min-height: var(--density-row-h);
  padding-block: var(--density-cell-y);
  gap: var(--density-gap);
  border-radius: var(--density-radius);
}
```

要点：

- 密度是**容器级**属性（表格容器、侧栏容器），不是根级。同一屏可以同时存在两种密度。
- 组件只引用 `--density-*`，不感知当前档位。
- 圆角随密度变小，否则紧凑表格里的 12px 圆角会显得过圆。

## 5. 各区域默认档位

| 区域 | 档 |
|---|---|
| 侧栏会话列表 | 紧凑 |
| 侧栏文件树 | 紧凑 |
| 消息流 | 标准（行距 16/4） |
| 输入区 | 标准 |
| 设置页 | 标准 |
| 数据表格 | 紧凑 |
| 菜单 / 下拉 | 紧凑 |
| 工具栏 | 紧凑 |
| 对话框 | 标准 |
| 终端 | 紧凑（由字号控制） |

## 6. 落地规则

1. 只有两档，按区域固定，不给用户切换。
2. 密度只改留白与圆角，不改字号。
3. 热区、焦点环、分隔线三项不随密度收缩。
4. 用容器级 `data-density` + 变量覆盖实现，组件不写分支。
5. 同一容器内不得混档。
