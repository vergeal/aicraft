# 08 · 布局与栅格

## 1. 窗口结构

基准窗口 1440×900。窗口内只有一层滚动，滚动发生在内容列内部，窗口本身永不滚动。

```
┌───────────────────────────────────────────────────────────┐
│ 顶栏 48px（拖拽区）：红绿灯 · 会话标题 · 右侧操作           │
├──────────────┬──────────────────────────────┬─────────────┤
│ 导航列 280   │ 工作区（画布）                │ 右侧面板     │
│ （可折 56）  │ 内容列 650 / 760 / 820        │ 320–560     │
│              │                              │（关闭时 0）  │
└──────────────┴──────────────────────────────┴─────────────┘
```

固定值：

| 项 | 值 |
| --- | --- |
| 顶栏高 | 48px |
| 红绿灯中线 | 22px（距顶） |
| 红绿灯左侧留白 | 88px（macOS） |
| 导航列宽 | 280px |
| 导航列折叠宽 | 56px |
| 工作区内容最大宽 | 820px |
| 会话内容最大宽 | 650px |
| 右侧面板宽 | `clamp(320px, 34vw, 560px)` |
| 表单内容宽 | 480px（单列）/ 640px（双列） |
| 设置内容宽 | 760px |

**禁止**：右侧面板固定占 45%；固定 45% 在 1280 宽下会把会话挤到不可读。

## 2. 顶栏

- 横跨整窗，左半段与导航列共用表面，右半段属于工作区。
- 顶栏主体是拖拽区（`-webkit-app-region: drag`），其中所有按钮 / 输入必须 `no-drag`。
- 不画横贯整条的分割线；只有顶栏右侧段与内容之间允许 0.5px 分隔。
- 标题字号 13 / 500，居中在该段；没有标题时显示当前页名（如"设置"）。
- 顶部与侧栏同表面，接缝处不得出现色差。

## 3. 导航列

| 元素 | 高 | 说明 |
| --- | --- | --- |
| 品牌区 | 36 | 顶部留 8px |
| 新建按钮 | 32–36 | 主按钮黑白 |
| 一级导航项 | 32 | 图标 16 + 文字 13 |
| 分组标题 | 25 | 11px / 500 / 弱色 |
| 会话行 | 29 | 13px，单行省略 |
| 项目行 | 30 | 带展开箭头 |
| 账户区 | 44 | 贴底 |

- 选中行有两个信号：底色 + 左缘 2px 指示条；不能只靠颜色。
- 列表可滚动，上下边缘 20px 渐隐（仅在实际可滚动时出现）。
- 折叠后只留图标列（56px），图标垂直居中对齐原行位置，禁止整体缩放。

## 4. 内容列

内容列是所有页面的主体容器：

```css
.content {
  width: 100%;
  max-width: var(--workspace-content-max-width);
  margin-inline: auto;
  padding-inline: 24px;
}
```

| 页型 | 列宽 |
| --- | --- |
| 会话 / 对话 | 650 |
| 长文 / 文档 | 760 |
| 列表 / 表格 / 设置 | 820 |
| 表单（单列） | 480 |
| 表单（双列） | 640 |
| 空状态 | 560–720 |

内容列居中，两侧多余空间留白，不拉伸正文。窗口宽度不足时先减内边距（24→16），再允许横向滚动（仅表格）。

## 5. 页面骨架

所有页面使用同一套纵向骨架：

```
页面头（可选，48–64）
  ├─ 标题 20/28/600
  ├─ 说明 13–14 / 次色
  └─ 右侧主操作（右对齐）
──────────────────────────
内容区（唯一滚动容器）
  ├─ 分组 1（标题 + 内容，间距 12）
  ├─ 分组之间 32
  └─ ...
──────────────────────────
底部操作条（可选，56–64，吸底，仅表单/编辑页）
```

| 区 | 高 | 内边距 |
| --- | --- | --- |
| 页面头 | 自动（最小 48） | 上 32 / 下 20 |
| 内容区 | 自适应 | 左右 24 |
| 底部操作条 | 56 | 左右 24，上 12 |

## 6. 栅格

- 栅格列宽以内容列为准，不做 12 栏系统。
- 单列：所有字段宽度 100%，但输入框最大 420px（超出部分留白）。
- 双列：`grid-template-columns: repeat(2, minmax(0, 1fr)); gap: 16px 20px`。
- 只有"两个字段天然成对"时才用双列（起止时间、宽高、姓名/工号），否则一律单列。
- 双列在 < 900px 时退化为单列。

## 7. 滚动

- 每个滚动容器只负责自己：导航列、内容区、右侧面板各自独立滚动。
- 使用 `overscroll-behavior-y: contain` 防止滚动穿透。
- `scrollbar-gutter: stable` 避免出现/消失时跳动。
- 滚动条宽 4–6px，仅悬停时可见；不使用 `scroll-behavior: smooth` 伪造惯性。
- 顶部 / 底部渐隐 20px，只在内容确实溢出时启用。

会话滚动另有规则，见 [14 AI 状态](14-ai-states.md)：距底 48px 内才自动跟随。

## 8. 右侧面板

- 默认关闭；打开时作为第三列，不覆盖会话。
- 贴窗口右边缘，圆角 0，左缘 0.5px 描边。
- 宽度 `clamp(320px, 34vw, 560px)`；窗口 < 1200 时改为覆盖式。
- 面板顶部与顶栏同高（48px），其标签条与顶栏共用一条基线。
- 打开 / 关闭不改变会话的滚动位置与草稿。

## 9. 响应式

| 宽度 | 布局 |
| --- | --- |
| ≥ 1200 | 280 / 自适应 / 面板 |
| 1000–1200 | 240 / 自适应 / 面板覆盖 |
| 768–1000 | 56 / 自适应 |
| < 768 | 侧栏抽屉，内容全宽，内边距 16 |

断点只控制栏宽与内边距，**不控制字号**。

## 10. 空、载、错

三种状态必须占用与正常内容相同的容器宽度与最小高度，避免出现时布局跳动。

| 状态 | 结构 |
| --- | --- |
| 空 | 图标（可选）→ 标题 18–20 → 说明 14 → 主操作（最多 1 个） |
| 加载 | 骨架 3–5 行，与真实内容同高；超过 400ms 才显示 |
| 错误 | 图标 + 原因 + 一个恢复操作；不显示技术堆栈 |

完整页面模板见 [11 页面模板](11-pages.md)。

## 11. 禁止

- 窗口级滚动、多层嵌套滚动。
- 内容列随窗口无限拉宽。
- 三栏同时使用不同圆角与不同底色（"三个卡片并排"）。
- 底栏固定时遮挡内容（必须给内容区加等量 `padding-bottom`）。
- 用绝对定位拼布局（除拖拽浮层、装饰光）。
