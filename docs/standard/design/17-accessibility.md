# 17 · 无障碍

## 1. 焦点

- 焦点环：`outline: 2px solid var(--v2-border-border-focus)`，`outline-offset: 2px`。
- 禁止用 `box-shadow` 画焦点环（会被裁切，且高对比模式下失效）。
- 焦点只在键盘输入时显示：`html[data-input-modality="pointer"]` 时隐藏环。
- 菜单、弹窗打开时焦点进入第一个可交互元素；关闭后归还给触发元素。
- 不允许焦点落到隐藏区域（面板关闭后其内部元素必须 `inert` 或 `display: none`）。

## 2. 键盘

| 键 | 行为 |
| --- | --- |
| Tab / Shift+Tab | 顺序移动，顺序与视觉一致 |
| Enter | 激活按钮 / 提交 |
| Space | 切换开关、复选 |
| Esc | 关闭浮层、退出编辑 |
| ↑ ↓ | 列表、菜单、命令面板 |
| ⌘K / Ctrl+K | 命令面板 |

- 所有功能必须可仅用键盘完成。
- 不允许自定义 Tab 顺序。
- 焦点陷阱只用于模态弹窗，且必须可用 Esc 退出。

## 3. 语义与状态

- 状态样式由 `aria-*` / `data-state` 驱动：

```html
<button aria-pressed="true">
<div role="switch" aria-checked="false">
<button aria-expanded="false" aria-controls="panel">
```

- 图标按钮必须有 `aria-label`。
- 装饰性图标 `aria-hidden="true"`。
- 动态区域：消息流 `aria-live="polite"`，错误 `role="alert"`。
- 自定义控件必须有对应 role；不允许用 `div` 模拟按钮。

## 4. 对比度

| 内容 | 最低 |
| --- | --- |
| 正文 | 4.5:1 |
| 大字号 / 粗体 | 3:1 |
| 图标（功能） | 3:1 |
| 控件边界 | 3:1 |
| 焦点环 | 3:1 相对相邻颜色 |

- 玻璃表面按最坏背景计算。
- 不允许用 `opacity` 降低文字对比度来表达次要（应用弱色令牌）。

## 5. 缩放与尺寸

- 200% 缩放下布局不重叠、不截断关键操作。
- 字号允许用户调整（正文 12–20），调整后行高联动。
- 命中区不小于 28×28；触摸设备 44×44。

## 6. 辅助功能

| 设置 | 响应 |
| --- | --- |
| `prefers-reduced-motion` | 关闭装饰动画，保留状态切换 |
| `prefers-reduced-transparency` | 玻璃切实色，移除 backdrop-filter |
| `prefers-contrast: more` | 描边与分隔加深，取消玻璃 |
| `forced-colors` | 全部使用系统 Canvas / CanvasText，移除阴影与高光 |
| 系统强调色 | 焦点与选中使用 `--v2-system-accent` |

## 7. 颜色之外的第二信号

以下信息不能只靠颜色：

| 信息 | 第二信号 |
| --- | --- |
| 当前导航项 | 左缘 2px 指示条 + 字重 |
| 选中 | 背景 + 勾选图标 |
| 错误 | 图标 + 文字 |
| 成功 | 对勾 + 文案 |
| 未读 | 圆点 + 加粗 |
| 拖放目标 | 插入线 |

## 8. 文案与朗读

- 按钮文案是动作，不是"点击这里"。
- 错误消息包含原因与下一步。
- 图片有 `alt`；纯装饰图片 `alt=""`。
- 链接与按钮语义区分，不混用。

## 9. 验收

1. 拔掉鼠标，纯键盘走完主要流程。
2. 打开 VoiceOver，能读出一级导航、当前项、按钮状态。
3. 系统开启"减少动态""增加对比度""降低透明度"后界面仍可用。
4. 200% 缩放下无横向滚动（表格除外）。
5. 所有图标按钮都有可读名称。
