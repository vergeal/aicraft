# 12 · 表单与校验

## 1. 字段结构

单个字段是"标签 / 控件 / 辅助文本"三件套，纵向排列：

```
标签（可选右对齐操作）        13px / 500
┌──────────────────────────┐
│ 控件                      │  高 32，内距 6 12
└──────────────────────────┘
辅助说明 或 错误文案          12px
```

| 元素 | 规格 |
|---|---|
| 字段容器 | `display: flex; flex-direction: column; gap: 6px; padding: 12px 0` |
| 字段分隔 | 相邻字段 `border-top: 0.5px solid border-l2` |
| 标签 | 13/20，字重 500，`label-primary` |
| 标签右侧操作 | 12–13px 文字按钮，`label-secondary` |
| 控件内距 | `6px 12px`（输入框、下拉、多行文本统一） |
| 控件边框 | `0.5px solid border-l4`，圆角 12 |
| 无效态 | `[aria-invalid="true"]` → 边框 `state-error-primary` |
| 错误文案 | 12px，`state-error-primary`，紧贴控件（gap 6） |
| 辅助说明 | 12px，`label-tertiary` |

**辅助说明与错误文案互斥**：有错误时用错误文案占位，不要两条都显示。

## 2. 两种布局

| 布局 | 适用 | 标签位置 |
|---|---|---|
| **堆叠**（默认） | 设置页、对话框、移动端 | 控件上方 |
| **行内** | 桌面端宽表单、开关类 | 左侧固定宽 160–200，控件右侧对齐 |

行内布局的硬要求：**标签列宽度固定**，否则右侧控件会参差不齐。标签过长时换行，不压缩控件。

## 3. 控件尺寸与对齐

| 控件 | 高 | 说明 |
|---|---|---|
| 输入框 / 下拉 / 单行 | 32 | 与按钮 `md` 不一致是刻意的：按钮 36 有视觉重量 |
| 多行文本 | 最小 80，可 `resize: vertical` | 禁止横向 resize（会破坏布局） |
| 开关 | 20 | 行内布局时与 32px 控件垂直居中 |
| 复选框 / 单选框 | 16 | 热区补到 24 |

**同一行的多个控件必须等高**；「输入框 + 后缀按钮」用容器统一高度，不要让按钮决定行高。

## 4. 校验时机

| 时机 | 行为 |
|---|---|
| 初始 | 不显示任何错误 |
| 输入中 | 不校验（避免"刚打一个字就报错"） |
| 失焦 | 校验该字段；通过则清除错误 |
| 提交 | 校验全部；滚动到第一个错误并聚焦 |
| 已报错后的输入 | **实时**重新校验，错误消失即清除 |

**错误出现后要能即时消失**，否则用户改对了还看着红框。

## 5. 必填与可选

两种表达，产品内统一：

| 方案 | 做法 |
|---|---|
| 标必填（推荐） | 标签后加 `*`（`state-error-primary` 或主色），并在表单顶部说明"带 * 为必填" |
| 标可选 | 在可选字段标签后加"（可选）"，`label-tertiary` |

不要两者混用。`*` 需要 `aria-required="true"` 或原生 `required`。

## 6. 字段分组

| 层级 | 样式 |
|---|---|
| 页面 | 最大宽 760，居中 |
| 分组 | 标题 13/20 `label-tertiary` + 卡片（`settings-card-fill` + `0.5px settings-card-stroke`） |
| 分组间距 | 24px |
| 组内字段 | 用 0.5px 分隔线，不用独立卡片 |

分组标题不是装饰：一组字段超过 5 个、或语义切换（账号 / 通知 / 高级），就必须分组。

## 7. 保存策略

| 类型 | 交互 | 适用 |
|---|---|---|
| **即时保存** | 改动即生效，右上角短暂提示"已保存" | 开关、单选、字号/主题等偏好 |
| **显式保存** | 底部粘性操作栏（取消 / 保存），未保存时离开需确认 | 多字段表单、危险配置 |

规则：

1. 一个页面只用一种保存策略，不要"部分即时部分手动"。
2. 即时保存时禁用态不应出现"保存中"，用行内小 spinner 代替。
3. 显式保存时，保存按钮在无改动时禁用。
4. 离开有未保存改动 → 拦截并确认，不要静默丢弃。

## 8. 危险操作

- 单独成组，置于最底部。
- 按钮用 danger 变体，**不要整块染红**。
- 必须二次确认，确认文案要复述后果（"删除后无法恢复"）。
- 破坏性操作的确认按钮不放在默认焦点上（默认焦点给"取消"）。

## 9. 落地规则

1. 字段 = 标签 + 控件 + 辅助/错误，纵向 gap 6，字段间 0.5px 分隔。
2. 控件高 32、内距 6 12、边框 0.5px、圆角 12，全表单统一。
3. 错误用 `aria-invalid` 驱动样式，不是独立 class。
4. 校验在失焦与提交时触发；报错后实时复核。
5. 一页只用一种保存策略；未保存离开必须确认。
6. 必填标记二选一，全产品统一。
7. 辅助文案与错误文案互斥。
