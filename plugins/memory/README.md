# Memory

跨会话记住用户的长期习惯与项目里重要的事实。记忆分两档：

- **全局记忆**：所有项目共享，例如「回复用中文」「偏好简洁的提交信息」。
- **项目记忆**：按 Project 隔离，只在该项目的会话中出现，例如「本项目用 bun」「测试只跑改动的文件」。

## 工具

| 工具 | 用途 |
| --- | --- |
| `memory.save` | 保存一条记忆，默认写入当前项目；跨项目习惯用 `global` |
| `memory.list` | 列出当前项目和全局记忆，按最近更新时间排序 |
| `memory.search` | 按关键词检索正文和标签 |
| `memory.update` | 修改正文或标签 |
| `memory.forget` | 删除指定 id 的记忆 |

项目由会话所属的 Project 决定，工具没有跨项目参数，因此项目记忆不会出现在其他项目里。

## 管理面板

桌面客户端里打开 **设置 → 记忆**，就能看到模型记住了什么：全局记忆和所选项目的记忆分组列出，支持搜索、新增、编辑和删除。面板与工具读写同一份存储，改动立即生效。

## 自动注入

每次主模型请求前，插件把当前项目的记忆和全局记忆作为系统提示的一部分注入。注入有字符预算，超出时按最近更新时间截断，并提示还有多少条可以用 `memory.search` 检索。

另有随插件分发的 `memory` 技能，教模型什么时候保存、选哪个范围，以及如何避免重复。

## 配置

| 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `autoInject` | boolean | `true` | 是否在每次请求前自动注入记忆 |
| `maxInjectedChars` | number | `4000` | 自动注入的字符上限 |
| `maxEntries` | number | `200` | 每个范围最多读取的条数 |

## 存储

记忆写入插件自己的 storage（由 OpenCode 管理），键前缀为 `entry/project/<projectID>/` 和 `entry/global/`。项目 ID 经过转义，不会越出所属前缀。

不要用它保存密钥、口令或令牌；这些应放在加密凭据或环境变量里。
