# 18 · 桌面端

## 1. 窗口

```ts
new BrowserWindow({
  width: 1440,
  height: 900,
  minWidth: 880,
  minHeight: 600,
  titleBarStyle: "hiddenInset",
  trafficLightPosition: { x: 18, y: 16 },
  vibrancy: "sidebar",
  visualEffectState: "followWindow",
  backgroundColor: "#00000000",
  webPreferences: {
    contextIsolation: true,
    nodeIntegration: false,
    sandbox: true,
  },
})
```

| 项 | 值 |
| --- | --- |
| 默认尺寸 | 1440×900 |
| 最小尺寸 | 880×600 |
| 顶栏高 | 48 |
| 红绿灯位置 | x 18 / y 16（中线 22） |
| macOS 左侧留白 | 88（红绿灯 14 + 节距 74） |
| 窗口圆角 | 由系统绘制，CSS 不再加圆角 |

规则：

- 窗口尺寸与位置记忆到本地，下次启动恢复；首次使用默认尺寸并居中。
- 不自定义红绿灯，不隐藏系统按钮。
- 不做自绘标题栏拖拽的"伪窗口"。

## 2. 材质

| 平台 | 窗口 | 侧栏 / 顶栏 | 内容区 |
| --- | --- | --- | --- |
| macOS（透明窗） | `vibrancy: "sidebar"` + `followWindow` | 半透明填充 + 系统材质 | 实色 |
| macOS（不透明窗） | 实色 | 实色 `bg-deep` | 实色 |
| Windows | 不透明 | 实色 rail（`#f7f7f7` / `#1a1a1a`） | 实色 |
| Linux | 半透明（若合成器支持） | 半透明 + 降级 | 实色 |

- 窗口根元素在透明窗下必须透明，才能露出系统材质；内容区必须自己铺不透明底。
- `prefers-reduced-transparency: reduce` 时：切实色、移除 `backdrop-filter`、窗口根部补背景色。
- Windows 不使用 Acrylic（桌面背景下发灰），统一不透明。

## 3. 拖拽区

- 只有顶栏是拖拽区：`-webkit-app-region: drag`。
- 顶栏内所有按钮、输入、标签、菜单触发器：`-webkit-app-region: no-drag`。
- 右侧面板若升入顶栏高度，其标签条必须 `no-drag`，否则点击被拖拽区吞掉。
- 拖拽区不覆盖可点击元素；用几何区域判断，不依赖 `pointer-events`。

## 4. 菜单与快捷键

- 使用原生应用菜单（`Menu.buildFromTemplate`），不在页面内重建完整菜单栏。
- 右键菜单使用原生菜单，从当前上下文生成；不在 DOM 内模拟。
- 快捷键在两处定义一次：应用菜单 + 渲染进程命令，映射表见 [12 导航](12-navigation.md)。
- Windows / Linux：`⌘` → `Ctrl`，`⌘,` → `Ctrl+,`。

## 5. 平台差异

| 项 | macOS | Windows | Linux |
| --- | --- | --- | --- |
| 窗口按钮 | 左侧红绿灯 | 右侧 caption（预留 138px） | 由桌面环境 |
| 材质 | vibrancy | 不透明 | 半透明可选 |
| 顶栏左内边距 | 88 | 12 | 12 |
| 顶栏右内边距 | 12 | 138 | 12 |
| 菜单 | 系统菜单栏 | 应用内菜单栏 | 应用内菜单栏 |
| 字体 | SF / PingFang | Segoe UI / 微软雅黑 | 系统默认 |

## 6. 启动

- 首屏必须在 `<head>` 内联背景色与 `color-scheme`，防止白闪。
- 启动骨架与最终界面同底色。
- 恢复上次窗口位置时，先显示窗口再渲染内容，避免"先白后暗"。
- 启动失败显示独立错误页（可重试、可查看日志），不留白屏。

## 7. 更新与崩溃

- 更新提示使用应用内浮层，不打断当前任务；提供"稍后"。
- 崩溃恢复：重新打开时恢复上次会话与草稿，提示"已恢复上次会话"。
- 日志入口固定在设置 → 关于。

## 8. 系统集成

| 能力 | 规则 |
| --- | --- |
| 文件拖入 | 顶栏以下任意位置可接收；拖入时显示目标区域反馈 |
| 外部链接 | 默认浏览器打开，不在应用内导航 |
| 通知 | 仅后台任务完成 / 需要输入时发送 |
| 剪贴板 | 复制内容保持纯文本，代码块保留语言标记 |
| 全屏 | 支持系统全屏，进入后顶栏保留拖拽与退出入口 |
| 深色模式 | 监听系统变化，无需重启 |

## 9. 性能

- 首屏可交互 ≤ 1.5s（M1，冷启动 3s）。
- 长会话（100 条消息）滚动 ≥ 55fps。
- 玻璃层数 ≤ 2，滚动区域内禁止 `backdrop-filter`。
- 内存常驻 ≤ 500MB（空会话）。

## 10. 禁止

- 自绘窗口控制按钮。
- 在渲染进程开启 `nodeIntegration`。
- 用 CSS 模拟系统弹窗 / 菜单。
- 把拖拽区设在内容区。
- 透明窗口下让 `body` 有实色背景（会盖住 vibrancy）。
- 在 Windows 上启用毛玻璃。
