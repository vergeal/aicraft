# 交付检查清单

提交前逐项勾选。任一项不通过即为不合格，不允许"先合并后修"。

## A · 令牌与色彩

- [ ] 组件内没有 `#hex`、`rgb()`、裸 `px` 字号、裸 `px` 圆角。
- [ ] 颜色只引用语义层（`--v2-background-* / text-* / icon-* / border-* / state-*`）。
- [ ] 文字只有四档：base / muted / faint / inverse。
- [ ] 边框只有三档：muted(8%) / base(10%) / strong(20%)。
- [ ] 状态色只用于状态，没有当强调色用。
- [ ] 强调整屏面积 ≤ 10%。
- [ ] 深色与浅色都验证过，深色未用纯黑背景。
- [ ] 首屏内联了背景色、`color-scheme`、字体与字号。

## B · 字体

- [ ] 字号只用 11 / 12 / 13 / 14 / 18 / 20（空状态 24–28）。
- [ ] 字重只用 400 / 500 / 600。
- [ ] 行高显式声明，中文正文 14/22。
- [ ] 数字使用 `tabular-nums`。
- [ ] 单行文本父级有 `min-width: 0`，能正确省略。
- [ ] 正文没有负字距或全大写。

## C · 间距、尺寸、形状

- [ ] 间距只用 2 / 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48。
- [ ] 控件高度在 24 / 28 / 32 / 36 / 40 / 44 / 48 内。
- [ ] 同一行控件高度一致，无 35px 类数值。
- [ ] 圆角只用 4 / 6 / 8 / 12 / 16 / 20 / 24 / 28 / 999。
- [ ] 胶囊只用于单行、≤ 40px 高、可数元素。
- [ ] 嵌套圆角按 `外层 − 内边距`。
- [ ] 贴边面板圆角为 0。
- [ ] 点击区域 ≥ 28×28。

## D · 层级与材质

- [ ] 每块浮层都能说清为什么浮着。
- [ ] 玻璃只用于浮在内容上的层，面积 ≤ 40%。
- [ ] 玻璃有实色降级，且响应 `prefers-reduced-transparency`。
- [ ] 同一屏玻璃层 ≤ 2，滚动区内无 `backdrop-filter`。
- [ ] 静态卡片无阴影。
- [ ] 阴影只用三档 elevation 令牌。
- [ ] 内高光只加在 Z2 以上，方向统一来自顶部。
- [ ] 模糊半径未做动画。

## E · 布局

- [ ] 顶栏 48、侧栏 280（折叠 56）、内容列按页型（650 / 760 / 820 / 480 / 640）。
- [ ] 内容列居中，未随窗口拉宽。
- [ ] 只有内容区滚动，窗口不滚动。
- [ ] 1440×900 / 1280×800 / 1024×768 都不挤、不空。
- [ ] 右栏宽度为 `clamp(320px, 34vw, 560px)`，未固定 45%。
- [ ] 内容列左右至少 24 留白。
- [ ] 滚动容器 `overscroll-behavior: contain` + `scrollbar-gutter: stable`。

## F · 组件

- [ ] 每个可交互组件五态齐全（default / hover / pressed / focus-visible / disabled）。
- [ ] 状态由 `aria-*` / `data-state` 驱动，无 `.is-active`。
- [ ] 一屏只有 1 个 primary 按钮。
- [ ] 禁用态使用 `disabled` + 视觉，不只改颜色。
- [ ] 纯图标按钮有 `aria-label`。
- [ ] 菜单 30 行、圆角 12；弹窗 480、圆角 24；Toast 320、圆角 16。
- [ ] 表格数字右对齐，分隔线只用横向。
- [ ] Composer 单行 24 圆角 / 多行 20 圆角，发送键 36×36。

## G · 表单与页面

- [ ] 字段 ≥ 4 时用页面或抽屉，不用弹窗。
- [ ] 标签在上、控件在下，无 placeholder 当标签。
- [ ] 校验在失焦与提交时发生，错误含原因与修法。
- [ ] 主操作文案是动词（创建 / 保存更改）。
- [ ] 有未保存修改时离开会确认。
- [ ] 危险操作独立分组、二次确认、按钮文案写明动作。
- [ ] 页面只有一个视线落点。
- [ ] 空 / 载 / 错三态齐备且不改变布局高度。

## H · 动效

- [ ] 时长在 85–300ms，曲线只用三条之一。
- [ ] 只动 transform / opacity / 颜色（折叠用 grid-rows）。
- [ ] 同一时刻 ≤ 1 个主要布局动画。
- [ ] 入场总时长 ≤ 550ms，再次进入不重播。
- [ ] 动画可中断、可取消，不排队。
- [ ] `prefers-reduced-motion` 关闭装饰但保留状态反馈。
- [ ] 发送到会话态是连续过渡，composer 未重建。
- [ ] 有键盘选中的列表用 `@opencode/ui/selection-indicator`，行内不再画选中背景（见 `13-motion.md` §10）。
- [ ] 指示器首次出现直接落位，移动 160ms `ease-out`，滚动时贴合选中行。
- [ ] 指示器圆角与行一致；容器有 `position: relative`。
- [ ] 指针连续扫过的区域（侧栏、整页列表）用 120ms 行背景过渡，不做滑动块。
- [ ] 浮层内容随查询增减时高度平滑跟随（200ms），首行到末行完整可见（见 §11）。
- [ ] 底部对齐浮层入场用独立 `scale` + `opacity`，不覆盖定位 `translate`。

## I · AI 状态

- [ ] 状态完整：Idle / Thinking / Tool / Streaming / Waiting / Completed / Failed / Interrupted。
- [ ] 思考用低频呼吸点，不用转圈或流光。
- [ ] 工具显示人话名称与目标，详情默认折叠。
- [ ] 流式输出不导致高度抖动，代码块预留空间。
- [ ] 距底 48px 内才自动跟随，向上阅读不被拉回。
- [ ] 中断保留已有内容，可继续。
- [ ] 失败提供恢复操作，不自动重试。

## J · 导航与桌面

- [ ] 侧栏选中项有两个信号（底色 + 2px 边条）。
- [ ] 折叠侧栏不缩放内容，只裁切 + 淡出。
- [ ] 顶栏是拖拽区，内部控件全部 `no-drag`。
- [ ] macOS 红绿灯左侧留白 88。
- [ ] 透明窗下内容区自铺不透明底，窗口根透明。
- [ ] Windows 不用毛玻璃，caption 区预留 138。
- [ ] 快捷键写进菜单与 Tooltip。

## K · 可访问性与文案

- [ ] 键盘可完成主流程，焦点环 2px + offset 2。
- [ ] 弹窗焦点进入与归还正确。
- [ ] 颜色之外有第二信号。
- [ ] 对比度：正文 ≥ 4.5，图标/边框 ≥ 3。
- [ ] 新增文案有中文，无字符串拼接，省略号用 `…`。
- [ ] 200% 缩放不重叠。

## L · 性能

- [ ] 首屏可交互 ≤ 1.5s。
- [ ] 100 条消息滚动 ≥ 55fps。
- [ ] 无滚动区 `backdrop-filter`，无动画 `filter`。
- [ ] 图片 / 代码块有预留尺寸，无布局位移。

---

**红线**（任一违反直接打回）：裸色值 · 全屏玻璃 · 弹窗放 4 个以上字段 · 状态只靠颜色 · 发送跳页重建 composer · 文档与实现冲突时改文档。
