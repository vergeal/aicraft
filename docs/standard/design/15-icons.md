# 15 · 图标与插画

## 1. 图标网格

- 统一 24×24 网格，视框 `viewBox="0 0 24 24"`。
- 描边式（line）为主，不用填充式，除非表示"已选中"状态。
- 描边宽度：16px 及以下用 1.75–2；20–24px 用 1.5–1.75；同一界面内只用一种。
- 线端与转角：`stroke-linecap="round" stroke-linejoin="round"`。
- 图标集：Lucide 为唯一来源；缺失图标按同一网格与线宽自绘，不引入第二套风格。

## 2. 尺寸

| 尺寸 | 用途 |
| --- | --- |
| 12 | 行内元信息、徽标内 |
| 14 | 菜单项、小型按钮 |
| 16 | 默认（按钮、导航、输入框） |
| 20 | 页面头、工具栏 |
| 24 | 空状态、提示 |
| 28–32 | 品牌 mark、空状态主视觉 |

图标尺寸必须是上表值；禁止 15、18、22。

## 3. 颜色

- 默认 `icon-base`；次要 `icon-muted`；禁用 / 装饰 `icon-faint`。
- 图标颜色必须与相邻文字同档，不允许"文字灰、图标黑"。
- 单色。**禁止**多色图标（品牌 mark、项目色块、状态点除外）。
- 禁止 emoji 作为功能图标。

## 4. 与文字的对齐

- 图标与文字基线对齐：使用 flex + `align-items: center`，必要时 `translateY(0.5px)` 光学校正。
- 图标与文字间距：按钮 / 菜单 6，导航项 10，提示条 8。
- 纯图标按钮的命中区 28×28，图标居中 16。
- 数字与图标同行时，数字使用 `tabular-nums`。

## 5. 状态图标

| 状态 | 图标 | 颜色 |
| --- | --- | --- |
| 成功 | check | `state-fg-success` |
| 警告 | triangle-alert | `state-fg-warning` |
| 危险 | circle-alert / x | `state-fg-danger` |
| 信息 | info | `state-fg-info` |
| 进行中 | 呼吸点（非图标） | 强调色 |
| 禁用 | 原图标 | `icon-faint` + `opacity .6` |

## 6. 插画

- 默认不使用插画。空状态优先用图标 + 文案 + 操作。
- 允许插画的场景：首次启动、关于页、重大空状态。
- 插画风格：单色线性 + 一层极淡填充，尺寸不超过 160×120。
- 禁止 3D、渐变球、AI 机器人、通用人物插画。
- 插画必须可被 `prefers-reduced-motion` 关闭动态。

## 7. 品牌资产

- 品牌 mark 使用品牌色渐变，独立于语义色，不参与主题切换。
- 只出现在侧栏品牌区、启动页、关于页；不出现在按钮、标题、卡片装饰中。
- 品牌 mark 最小尺寸 20，小于该值改用单色版本。

## 8. 禁止

- 混用两套图标风格（线性 + 面性）。
- 图标加投影、发光、彩色渐变。
- 用图标替代文字标签（一级导航必须图标 + 文字）。
- 图标尺寸随容器随意缩放（必须按尺寸档位渲染）。
- 在深色底上使用纯黑描边图标。
