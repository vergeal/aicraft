# 14 · AI 交互状态

AI 界面的辨识度来自"工作过程被看见"，而不是转圈。所有状态必须可枚举、可测试、可无障碍读取。

## 1. 状态机

| 状态 | 触发 | 界面 | 用户可做 |
| --- | --- | --- | --- |
| Idle | 无任务 | 静止，无装饰 | 输入、发送 |
| Thinking | 已提交，未产出 | 低频呼吸点 + 一句话 | 停止 |
| Tool Running | 正在调用工具 | 工具名 + 阶段 + 可展开详情 | 停止、展开 |
| Streaming | 正在输出文本 | 文本逐段出现 + 光标 | 停止、追加指令 |
| Waiting Input | 需要用户确认 | 强调块 + 明确选项 | 确认 / 取消 |
| Completed | 正常结束 | 中性完成标记，不常驻 | 继续、复制 |
| Failed | 出错 | 原因 + 重试 | 重试、查看详情 |
| Interrupted | 用户中断 | 保留已产出内容 + 恢复入口 | 继续、重发 |

同一会话中可以同时存在多个已完成步骤与一个进行中状态；进行中状态最多一个。

## 2. 视觉规格

| 元素 | 规格 |
| --- | --- |
| 状态行高 | 20 |
| 状态文字 | 12 / 18 / 次色 |
| 呼吸点 | 7px，`opacity .45→1`，2.4s，`ease-in-out` |
| 步骤行 | 28 高，图标 14，缩进 0 |
| 步骤详情 | 默认折叠，展开后用等宽 12/18，最大高 240 内滚动 |
| 等待块 | 底色 `bg-layer-02`，圆角 12，内边距 12 |
| 错误块 | 危险底 8%，左侧 2px 危险条，圆角 8 |

**禁止**：转圈 spinner 作为唯一反馈；用进度条百分比伪造确定性；彩色流光。

## 3. Thinking

- 显示一句话，说明在做什么："正在读取项目结构…""正在分析 12 个文件…"。
- 文案随阶段更新，不循环切换无意义提示。
- 超过 10s 追加一行"仍在进行，可随时停止"。
- 超过 60s 提供"继续等待 / 停止"。

## 4. Tool Running

- 必须显示：工具名（人话）、目标（文件 / 网址 / 命令）、状态。
- 工具名不用内部函数名："读取文件"而不是 `read_file`。
- 多步骤用列表，每步一行：
  - 已完成：对勾（弱色）
  - 进行中：呼吸点
  - 待执行：空心点（弱色）
- 默认折叠详情；展开显示参数与结果摘要，不显示完整堆栈。
- 失败步骤标红，但不打断后续可恢复步骤。

## 5. Streaming

- 文本按段落出现，不逐字闪动。
- 光标不改变行高：使用伪元素 2px 竖条，`height: 1em`。
- 代码块先占位（最小高 96）再填充，避免滚动跳动。
- 流式输出期间不重新计算整段布局；每个新段落追加，不替换。
- 完成后不做"整体重排"或重新高亮导致闪动。

## 6. 滚动跟随

| 条件 | 行为 |
| --- | --- |
| 距底 ≤ 48px | 自动跟随新内容 |
| 距底 > 48px | 停止跟随，显示"有新消息 ↓" |
| 用户点击回到底部 | 恢复跟随 |
| 用户发送新消息 | 强制回到底部 |
| 工具展开 / 图片加载 | 不改变锚点，不跳动 |

- 图片、附件、代码块必须预留尺寸（`aspect-ratio` / 最小高）。
- 顶部渐隐 20px 仅在内容溢出时启用。

## 7. Waiting Input

场景：需要确认执行危险命令、选择方案、补充参数。

```
┌──────────────────────────────────┐
│ 需要你确认                        │ 13/500
│ 将在 opencode 目录执行 3 条命令    │ 14/次色
│ [查看命令]（ghost）                │
│                     [取消] [执行] │
└──────────────────────────────────┘
```

- 必须写清"要发生什么"和"影响范围"。
- 选项 2–3 个；主选项明确动作。
- 等待期间输入框仍可用，但发送按钮文案变为"追加说明"。
- 不允许自动消失。

## 8. Completed

- 完成标记使用中性色 + 对勾，不使用绿色大色块。
- 可提供 1–2 个后续动作（复制、继续、打开文件），默认不抢眼。
- 完成后 3s 内不收起任何已展开内容，避免用户正在看时消失。

## 9. Failed

- 一句话原因 + 一个恢复操作。
- 错误码与技术细节收进"查看详情"。
- 已产出的内容保留，不回滚、不清空。
- 网络类错误提供"重试"；权限类提供"切换账号"；参数类提供"修改后重发"。

## 10. Interrupted

- 用户点击停止后立即生效，1s 内不再产出。
- 保留已产出内容，末尾显示"已停止 · 继续"。
- 恢复时从断点继续，不从头重来。
- 中断不产生错误态样式。

## 11. 文案规则

| 位置 | 示例 | 禁止 |
| --- | --- | --- |
| 状态 | 正在读取项目结构… | 思考中…（空泛） |
| 工具 | 正在运行测试 | 调用 tool_runner |
| 等待 | 需要你确认后继续 | 请稍候 |
| 完成 | 已完成 · 修改 3 个文件 | 成功！ |
| 失败 | 无法连接到模型服务，请重试 | 出错了 |
| 中断 | 已停止 · 继续 | 已取消操作 |

所有状态文案走 i18n，并使用省略号 `…` 表示进行中。

## 12. 无障碍

- 状态容器 `aria-live="polite"`；错误 `role="alert"`。
- 状态变化不能只靠颜色：必须有文字或图标。
- 呼吸动画在 `prefers-reduced-motion` 下静止为 80% 不透明。
- 停止按钮始终可通过键盘到达（`Esc` 也可停止）。

## 13. 禁止

- 用彩色动画表达"AI 在思考"。
- 输出过程中整体高度抖动。
- 中断后清空已有结果。
- 失败时自动重试且不告知用户。
- 工具详情默认展开（噪音过大）。
- 同时出现两个进行中状态。
