# 12 · 导航与信息架构

## 1. 层级

产品只有三层导航，不允许出现第四层：

1. **一级**：左侧导航列（收件箱、定时任务、知识库、探索、项目会话）。
2. **二级**：顶栏的会话标题 / 页面标题 + 页面内标签页。
3. **三级**：右侧面板内的标签页（属性、活动、预览）。

面包屑只在"对象详情存在父子关系"时使用，最多 3 段，末段为当前对象且不可点。

## 2. 侧栏

| 项 | 值 |
| --- | --- |
| 宽 | 280（折叠 56） |
| 顶部留白 | 8 |
| 品牌区高 | 36 |
| 新建按钮 | 32–36，主按钮 |
| 一级项高 | 32 |
| 分组标题 | 25，11/500/弱色 |
| 会话行高 | 29 |
| 项目行高 | 30 |
| 行内边距 | 0 10 |
| 行圆角 | 6 |
| 底部账户 | 44 |

规则：

- 选中项 = 底色 + 左缘 2px 指示条，两个信号。
- 折叠时隐藏文字，保留图标；禁止把整列 `scale` 缩小。
- 折叠 / 展开 220ms `cubic-bezier(.2,0,0,1)`，标签淡出快于面板收缩。
- 可滚动，上下渐隐 20px。
- 拖拽排序时显示 2px 插入线，被拖行 `opacity .45`。
- 项目组展开用 `grid-template-rows: 0fr → 1fr`，不用 `height` 动画。

## 3. 顶栏

- 高 48；左段与侧栏同表面，右段属于工作区。
- 标题 13 / 500，单行省略；标题右侧可放一个 20px 胶囊标签（如"临时聊天"）。
- 右侧操作：图标按钮 28，间距 4；最多 4 个，多余收进菜单。
- macOS 红绿灯左侧留白 88px；折叠侧栏时右段左内边距 92。
- 拖拽区覆盖整条顶栏，内部所有可交互元素 `-webkit-app-region: no-drag`。

## 4. 标签页

| 项 | 值 |
| --- | --- |
| 条高 | 52（与顶栏齐平时 48） |
| 标签高 | 32 |
| 标签内边距 | 0 12 |
| 字号 | 13 / 500（未选 400 / 次色） |
| 当前指示 | 2px 底线 或 胶囊底，二选一 |

- 标签 ≤ 6 个，超出横向滚动，不换行。
- 关闭按钮 16，仅 hover / 当前项可见。
- 切换 160ms，指示器位移用 `transform`，不重排。

## 5. 命令面板

`⌘K` 打开，Z4 浮层：

| 项 | 值 |
| --- | --- |
| 宽 | 560 |
| 最大高 | 420 |
| 圆角 | 16 |
| 材质 | 玻璃厚（`blur(40px)`） |
| 输入行 | 48 |
| 结果行 | 36 |
| 分组标题 | 11 / 500 / 弱色 |

- 输入即筛选，300ms 内出结果。
- 结果分三组：导航、最近会话、命令。
- 上下键移动，回车执行，Esc 关闭。
- 空结果给一条建议（"没有匹配的命令，试试 ⌘N 新建会话"）。

## 6. 快捷键

| 快捷键 | 行为 |
| --- | --- |
| `⌘N` | 新会话 |
| `⌘K` | 命令面板 |
| `⌘,` | 设置 |
| `⌘W` | 关闭当前会话标签 |
| `⌘B` | 折叠 / 展开侧栏 |
| `⌘/` | 快捷键一览 |
| `Esc` | 关闭浮层 / 退出输入 |
| `↑ ↓` | 列表与命令面板移动 |
| `↵` | 执行 / 发送 |

- 快捷键必须写进菜单与 Tooltip，不允许只存在于代码。
- Windows / Linux 用 `Ctrl` 替代 `⌘`，由平台层映射。

## 7. 返回与历史

- 窗口返回栈按会话记录，切回会话恢复滚动位置与草稿。
- 关闭会话标签不销毁其状态，再次打开恢复。
- 返回按钮只出现在顶栏左侧（macOS 可省略，用系统手势）。

## 8. 导航文案

| 层级 | 长度上限 | 示例 |
| --- | --- | --- |
| 一级导航 | 4 字 | 收件箱、定时任务 |
| 项目名 | 24 字（超出省略） | opencode |
| 会话名 | 32 字（超出省略） | 设计规范评审 |
| 页面标题 | 16 字 | 项目设置 |
| 标签页 | 6 字 | 属性、活动 |

## 9. 禁止

- 一级导航出现图标 + 纯英文混排。
- 侧栏同时出现两套选中样式。
- 标签页超过两层（面板内再开标签页）。
- 用折叠导航隐藏"必须可达"的主入口（设置必须在账户菜单或 ⌘, 可达）。
- 顶栏拖动区吞掉按钮点击（必须 `no-drag`）。
