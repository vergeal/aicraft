# 15 · 导航体系

## 1. 三层结构

| 层 | 组件 | 位置 | 承载 |
|---|---|---|---|
| 全局 | 侧栏 | 左，固定 | 一级功能域、会话/文件列表 |
| 局部 | 页签 / 分段控件 | 内容区顶部 | 同一功能下的视图切换 |
| 页内 | 面包屑 / 锚点 | 内容区顶部 | 层级定位与跳转 |

三层同时出现时，**视觉权重必须递减**：侧栏最重（有色块选中），页签次之（底线指示），面包屑最轻（纯文字）。

## 2. 侧栏

| 参数 | 值 |
|---|---|
| 展开宽 | 280 |
| 折叠宽（图标栏） | 56 |
| 自动折叠阈值 | 1024（视口宽） |
| 抽屉阈值 | 768 |
| 水平内距 | 8 |
| 列表行内距 | 12 |
| 行高 | 32–36（紧凑档 28） |
| 图标与文字间距 | 6 |
| 圆角 | 8 |
| 选中底色 | `sidebar-nav-item-active` |
| 选中标记 | 左侧 2px 竖条（可选，与底色二选一） |

**分组**：一级导航与"会话/文件列表"之间用 12–16px 空隙 + 可选的 13px 分组标题（`label-tertiary`）分隔，不用分隔线。

**折叠态**：只保留图标，图标居中；hover 出 tooltip 补全名称。折叠不是 `display: none`，宽度要变成 56 并保留图标，否则用户失去入口。

**拖拽调宽**（若支持）：只允许在 200–400 之间；双击手柄回到 280；宽度写入本地存储。

## 3. 页签（Tab）

| 参数 | 值 |
|---|---|
| 高度 | 36（紧凑 32） |
| 内距 | `0 12px`（热区向外扩 10） |
| 字号 | 13/20 |
| 指示器 | 2px，位于底部，宽度与文字等宽 |
| 未选中 | `label-secondary` |
| 选中 | `label-primary` |
| 悬停 | `interactive-bg-hover`（仅在可悬停设备） |
| 关闭按钮 | 14px，hover 才出现，距文字 6 |

**页签 vs 分段控件**：页签用于"多个并存的内容视图"（可关闭、可拖拽排序）；分段控件用于"同一数据的互斥视图"（不关闭、等宽）。二者不要互换。

## 4. 面包屑

| 项 | 规格 |
|---|---|
| 字号 | 12–13px，`label-tertiary` |
| 分隔符 | `/` 或 `›`，与文字间距 6 |
| 当前页 | `label-primary`，不可点 |
| 折叠 | 超过 4 级时折叠中间为 `…`，点击展开 |
| 最小/最大 | 至少显示首尾两级 |

桌面客户端里面包屑常与"后退"按钮成对出现——两者职责不同：面包屑表达**层级**，后退表达**历史**。

## 5. 返回栈

| 行为 | 规则 |
|---|---|
| 后退 | 回到上一个视图，保留其滚动位置与展开状态 |
| 前进 | 仅在用户刚后退过时可用 |
| 关闭页签 | 不进入历史栈 |
| 切换一级导航 | 进入历史栈 |
| 键盘 | `Alt+←` / `Alt+→`（macOS `⌘+[` / `⌘+]`） |

**状态保留是硬要求**：后退回去发现列表滚动位置丢了，比不能后退更烦。

## 6. 命令面板

| 项 | 值 |
|---|---|
| 宽 | `min(640px, 100vw - 48px)` |
| 位置 | 顶部居中，距顶 10–15vh |
| 输入框 | 高 44，无边框，仅底部 0.5px 分隔 |
| 结果行 | 高 36，图标 16 + 主文案 13/20 + 右侧快捷键 |
| 可见行数 | 8–10，超出滚动 |
| 高亮 | 匹配片段加粗，不用背景色 |
| 空结果 | 一行"没有匹配的命令" + 建议动词 |

## 7. 选中态规范

| 场景 | 表现 |
|---|---|
| 侧栏项 | 填充 `bg-selected`，文字升为主色 |
| 页签 | 底部 2px 指示器 + 文字升主色 |
| 分段控件 | 白色滑块（`bg-layer-1` + `elevation-soft`） |
| 表格行 | 填充 `bg-selected`，不加边框 |
| 卡片 | 描边升为 `border-strong` |

**选中态永不只用颜色深浅区分**：必须同时有形状或位置信号（竖条、下划线、滑块），否则色弱用户无法识别。

## 8. 键盘可达

| 键 | 行为 |
|---|---|
| `Tab` | 在导航控件间移动（一组内用 roving tabindex，只保留一个 tabindex=0） |
| `↑ ↓` | 在列表/菜单项间移动 |
| `← →` | 在页签/分段控件间移动 |
| `Enter` / `Space` | 激活 |
| `Home` / `End` | 跳到首/末项 |
| `Esc` | 关闭浮层，焦点回到触发元素 |

## 9. 落地规则

1. 三层导航的视觉权重必须递减。
2. 侧栏折叠保留图标与宽度，不做 `display: none`。
3. 页签管内容视图，分段控件管互斥视图，不互换。
4. 后退必须恢复滚动位置与展开状态。
5. 选中态必须有形状信号，不能只靠颜色。
6. 一组导航控件用 roving tabindex，避免 Tab 键穿过十几项。
