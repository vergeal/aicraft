# 11 · 表格与数据列表

## 1. 排版规格

| 项 | 值 | 依据 |
|---|---|---|
| 字号 | 13px | 表格正文比 UI 默认小一档，换取列密度 |
| 行高 | 22px | 随正文字号轴联动缩放 |
| 表头字重 | 500 | 正文 400 |
| 单元格内距 | `6px 12px` | 纵向紧、横向松，便于扫读 |
| 分隔线 | `0.5px` `border-l2` | 不用 1px，也不给每行都画 |
| 表头背景 | `bg-subtle` | 与内容区分，不用重色 |
| 圆角 | 容器 8–12，且需 `overflow: hidden` 裁切 | — |

**行高与字号联动**：若产品支持字号调节，表格行高应写成 `calc(22px + delta)`，否则调大字号后表格会挤成一行。

## 2. 分隔线策略

三选一，不要混用：

| 方案 | 适用 | 做法 |
|---|---|---|
| **仅横向**（推荐） | 大多数数据表 | 每行 `border-bottom: 0.5px border-l2`，去掉竖线 |
| 横向 + 表头下边线 | 需要强调表头 | 表头 `border-bottom: 1px border-strong` |
| 全网格 | 财务/对比类，单元格需要独立边界 | 仅在明确需要时 |

**不要斑马纹 + 分隔线同时用**。两者叠加会让眼睛在行间来回跳。

## 3. 对齐规则

| 内容类型 | 对齐 | 原因 |
|---|---|---|
| 文本、名称、标题 | 左 | 阅读起点一致 |
| 数字、金额、百分比 | **右** | 位数对齐才能比较 |
| 日期 | 左（或右，全表统一） | — |
| 状态/标签 | 左（标签本身居中） | — |
| 操作按钮 | 右 | 与滚动条保持距离 |
| 表头 | 与列内容一致 | 数字列的表头也右对齐 |

数字列必须 `font-variant-numeric: tabular-nums`，否则 1 和 8 宽度不同，列会轻微抖动。

## 4. 宽表处理（关键机制）

窄容器里的宽表有两种解法，成熟做法是"突破阅读列宽 + 保留原位起点"：

```css
.table-wide {
  /* 距阅读列外缘还有多少余量，窄屏时为 0 */
  --table-spare: max(0px, calc((100cqw - var(--content-width)) / 2));
  /* 需要向左探出的距离，让表格内容仍从原 x 开始 */
  --table-lead: calc(var(--table-spare) + min(var(--content-width), 100cqw) - 100%);

  width: calc(100% + var(--table-lead) + var(--table-spare));
  max-width: none;
  margin-left: calc(-1 * var(--table-lead));
  padding-left: var(--table-lead);   /* 内容起点不变 */
}
```

要点：

1. 用**容器查询单位 `cqw`**，不用 `vw`——三栏布局下视口宽不等于可用宽。
2. `--table-spare` 钳到 0，保证窄屏时退回普通"列内横向滚动"，不会左右乱跳。
3. `margin-left` 负值与 `padding-left` 正值相等，内容起点不动，只有背景/边框外扩。
4. 加 `position: relative; z-index: 1` 给实际 `<table>`，避免被同级的拖拽手柄压住。

## 5. 滚动与吸附

| 场景 | 做法 |
|---|---|
| 超过列宽 | 外层 `overflow-x: auto`，表头 `position: sticky; top: 0` |
| 首列是标识（文件名/用户名） | 首列 `position: sticky; left: 0`，并给右侧 0.5px 阴影分隔 |
| 左右都有吸附 | 吸附列必须有不透明背景，否则内容会透上来 |
| 表格自身滚动 + 页面滚动 | 只允许表格横向滚动，纵向交给页面；不要嵌套纵向滚动 |

## 6. 列宽分配

| 列类型 | 策略 |
|---|---|
| 标识列（名称/ID） | `min-width: 120px` + `max-width: 320px` + `truncate`；`width: 100%` 吃掉剩余空间 |
| 数值列 | 固定宽（80–120px），`width: 1%` + `white-space: nowrap` |
| 状态列 | 固定宽（100–140px） |
| 操作列 | 固定宽，`width: 1%`，右对齐 |
| 时间列 | 固定宽，nowrap |

**总原则**：只有一列"弹性"，其余列固定或按内容收缩。列数 > 6 时优先减少列（用展开行/details），而不是压缩列宽。

## 7. 排序、筛选与选择

| 交互 | 规格 |
|---|---|
| 排序指示 | 表头右侧 12px 箭头，默认隐藏，hover/激活时出现；激活列的表头文字色升为主色 |
| 多列排序 | 指示器带序号（1/2），否则不给多列排序 |
| 筛选 | 表头行下方的 chip 区，不放在单元格内 |
| 行选择 | 首列 16px 复选框；表头复选框支持半选态（`indeterminate`） |
| 批量操作 | 选中后浮出工具条，显示"已选 N 项" + 操作 + 取消 |
| 行操作 | 行尾 ⋯ 菜单；**不要**每行平铺多个按钮 |

## 8. 状态

| 状态 | 表现 |
|---|---|
| 空 | 表头保留 + 一行居中说明 + 主操作；不要整表消失 |
| 加载（首次） | 3–5 行骨架，保持列宽 |
| 加载（刷新） | 表头下方 2px 进度条，内容不闪 |
| 错误 | 表头保留 + 错误说明 + 重试按钮 |
| 无结果（筛选后） | 说明"没有匹配项" + 清除筛选按钮，与"空表"文案不同 |
| 值为空 | 显示 `—`（em dash），不用空白、不用 `null` |

## 9. 长列表

| 问题 | 解法 |
|---|---|
| 万行卡顿 | 虚拟滚动；固定行高（28/32/36）才能精确计算 |
| 行高不定 | 用 `content-visibility: auto` + `contain-intrinsic-size` 兜底 |
| hover 抖动 | 只改背景色，不加 border/transform |
| 选中行 | 用 `bg-selected` 填充，不加边框 |
| 键盘导航 | 行内可聚焦元素走 roving tabindex，↑↓ 移动、Enter 进入 |

## 10. 落地规则

1. 字号 13、行高 22（可随字号轴缩放），表头 500。
2. 只用横向 0.5px 分隔线；不叠加斑马纹。
3. 数字右对齐 + `tabular-nums`。
4. 宽表用容器查询突破，不用 `vw`；窄屏退回列内滚动。
5. 只保留一列弹性宽度，其余固定。
6. 空值统一 `—`，空表与无结果必须区分文案。
7. 纵向滚动交给页面，表格只横向滚动。
