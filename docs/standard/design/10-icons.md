# 10 · 图标系统

## 1. 网格与描边

素材实测：2695 个图标中 **2407 个使用 `viewBox="0 0 24 24"`**，其余为 16 / 18 / 20 的专用图形。

| 项 | 值 | 依据 |
|---|---|---|
| 主网格 | 24×24 | 占比 89% |
| 标准描边 | 2px | 1420 个图标；视觉重量与 14px 文字匹配 |
| 细线描边 | 0.5px | 284 个；用于密集面板与分隔性图标 |
| 绘制安全区 | 内缩 2px | 24 网格内容实际占 20×20，避免贴边被裁 |
| 端点 | `stroke-linecap: round`、`stroke-linejoin: round` | 全库一致 |
| 填充 | `fill: none` + `stroke: currentColor` | 线性图标默认 |

> **2px 在 24 网格上是"中间值"**：18 网格用 1.5，20 网格用 1.75，16 网格用 1.25。若必须跨网格混用，按 `描边 = 网格 / 12` 换算，不要所有网格都用 2px。

## 2. 双权重体系（可直接照搬）

实现 B 的图标源码里，同一个字形提供两个权重，**命名与尺寸解耦**：

```
IconSearchOutlineRegular    // 1px 描边
IconSearchOutlineMedium     // 1.3px 描边
```

三条设计决策值得记录：

1. **权重进名字，尺寸不进名字**。`IconSearchOutlineRegular` 可渲染 16/20/24 任意尺寸；不叫 `IconSearch16`，否则尺寸一改就要重命名。
2. **尺寸是 prop，默认值来自 artwork 元数据**。图标可带长宽比（`aspect`），渲染时按 `size × (w/h)` 计算宽度，非方形图标不变形。
3. **artwork 可由主题替换**。图标通过 document 里的 `<symbol>` sprite 渲染：

```html
<svg width={size} height={size} data-icon="icon-search-outline-regular" aria-hidden="true">
  <use href="#icon-search-outline-regular" />
</svg>
```

调用方只依赖 symbol id，主题换一套 artwork 不需要改任何组件。

## 3. 尺寸

| 尺寸 | 用途 | 配套文字 |
|---|---|---|
| 12–14 | 极密列表的前缀标记 | 11–12px |
| **16** | **默认**：按钮内、菜单项、输入框前缀、标签 | 13–14px |
| 20 | 工具栏、侧栏一级导航 | 14px |
| 24 | 空状态、卡片标题、对话框 | 16–20px |
| 32–48 | 空状态插图（非图标） | — |

图标与文字的水平间距：**4px**（紧凑）或 **6px**（常规）。不要 8px 以上，否则视觉上脱开。

## 4. 光学对齐

线性图标在方形网格里**视觉重心不等于几何中心**。两条硬规则：

1. **圆形、三角形要轻微放大**。24 网格里，圆形直径取 18–19（不是 20），三角形高度取 20 并下移 0.5px，才能与同尺寸方形看起来一样大。
2. **成对图标要按视觉平衡微调**。播放/暂停、展开/收起这类成对图标，单独看是对的，并排看会一高一低——需要在 artwork 阶段对齐，不能靠 CSS 补。

## 5. 颜色与状态

- 图标一律 `currentColor`，由父级文字色决定，**不单独设色**。
- 禁用态跟随父级 `opacity`，不改图标颜色。
- 多色/品牌图标是独立体系（用 `fill`，不参与 `currentColor`），需在图标集里单独分类。
- 状态图标（成功/警告/错误）成套提供，不在运行时给普通图标染色：

| 语义 | 图标风格 | 颜色 |
|---|---|---|
| success | 圆形 + 勾 | `state-success-primary` |
| warning | 三角 + 叹号 | `state-warn-primary` |
| error | 圆形 + 叉 | `state-error-primary` |
| info | 圆形 + i | `state-business-primary` |
| loading | 圆环 | 继承文字色，`opacity` 呼吸 |

## 6. 无障碍

- 纯装饰图标必须 `aria-hidden="true"`（实现 B 的每个图标都默认加）。
- 图标按钮必须提供可读名称：优先可见文字，其次 `aria-label`；**不要用 `title` 代替**（移动端与部分读屏不可用）。
- 图标按钮的点击热区 ≥ 24×24；16px 图标至少补 4px padding。

## 7. 图标集管理

1. **单一来源**。一个产品只允许一套描边风格；混入第三方图标时，先统一描边宽度与端点。
2. **命名按语义**：`search-outline` / `new-chat-outline`，不用 `magnifier` / `plus2`。
3. **成组交付**：同一场景的图标（工具栏一组、状态一组）成套评审，避免逐个积压成风格杂糅。
4. **导出规范**：`viewBox` 保留，`width/height` 移除，`fill/stroke` 用 `currentColor`。
5. **体积**：sprite 化后单图标平均 < 1KB；超过 200 个图标时按功能域拆多个 sprite，避免首屏加载全部。

## 8. 落地规则

1. 主网格 24，描边 2，内容留 2px 安全区；夸网格时按网格/12 换算描边。
2. 图标命名不含尺寸，尺寸走 prop。
3. 图标默认 `aria-hidden`，图标按钮必有可读名。
4. 图标只继承 `currentColor`，状态色由成套的状态图标承担。
5. 圆/三角按视觉尺寸放大，成对图标成对齐交付。
6. 全产品只允许一种描边风格。
