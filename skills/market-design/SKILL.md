# 应用市场设计

这套语言用于「有很多条目要浏览」的界面：探索页、应用市场、插件与技能目录、资源库。它的目标不是好看一时，而是在条目涨到数万时仍然好用。

下面的数值都来自实际界面的反复调优，不是草稿值。改之前先问自己：改了之后，条目变多时还成立吗？

## 形态：列表，不是卡片墙

- 用双列列表，不要卡片网格，也不要把分类塞进一个抽屉式目录。卡片墙在条目上百后就会失去节奏，抽屉会让人先猜目录再找东西。
- 搜索必须在首屏第一屏出现，并且是主控件。分类只是把已加载的结果分组，不是浏览的唯一路径。
- 结构按这个顺序：标题 → 搜索与操作 → 范围筛选（可选）→ 分类分组 → 条目行。
- 内容列居中，最大宽度约 880–960px。页面用深色背景，行本身没有边框、没有卡片底色；层次靠间距、字号和悬浮底色表达。

## 页面头部

- 左：类型切换（如「插件 / 技能」）放在最左，和标题的视觉基线对齐；标题 30px / 600，字距 -0.03em；副标题 14px，用次要文字色，与标题间距 9px。
- 右：搜索框、刷新按钮、主操作胶囊。工具栏顶部对齐，间距 4px。
- 宽度不足 900px 时，头部改为纵向堆叠，工具栏占满一整行，搜索框自适应宽度。

## 工具栏尺寸

这些是调优后的上限，不要放大：

| 控件 | 尺寸 | 说明 |
| --- | --- | --- |
| 搜索框 | 200 × 32，圆角 16 | 内距 `0 11px`，图标与文字间距 7px，输入 13px |
| 图标按钮 | 30 × 30，圆形 | 刷新这类单图标操作 |
| 主操作胶囊 | 高 32，圆角 16 | 内距 `0 12px`，图标与文字间距 4px，文字 13px / 500 |

- 36 以上的控件高度、238 宽的搜索框，在真实界面里会显得笨重并挤压标题区；不要照抄设计稿的大号版本。
- 主操作是全页唯一的高对比控件（浅底深字），其余控件用低对比背景。

## 条目行

- 横向结构固定为：40px 身份标 → 名称与描述 → 尾部动作。
- 名称 14px / 500，单行省略；描述 13px，单行省略，用次要文字色。两行间距 2px。
- 尾部动作只放一个：未安装显示 `+`（直接安装），已安装显示 `✓`（进入详情）。整行可点击进入详情。
- 分组标题 16px / 600，组间距 56px；组内行间距 2–4px。不要让组标题变成另一种卡片。
- 行高由内容撑开，不写死；悬浮与聚焦用背景色，不用位移。

## 身份标（图标）

身份标是这套界面里唯一允许写死颜色的地方，因为它是内容而不是装饰。

- 一个完整方形：`viewBox="0 0 24 24"`，底色用 `rect` 画满 `width="24" height="24" rx="7"`。
- 在列表里铺满 40×40；外层容器 `border-radius: 10px; overflow: hidden`，底色的圆角会被裁到 10px，所以不要另加边距或内缩。
- 图形包围盒的中心必须落在 `(12, 12)`：分别算 `(minX + maxX) / 2` 和 `(minY + maxY) / 2`。视觉重心偏 0.5 像素在 24px 下就看得出没居中。
- 只用直线、圆、椭圆和对称弧。手写的自由贝塞尔曲线缩小后一定糊，这是最常见的「像小学生画的」来源。
- 线宽 1.2–1.6，`stroke-linecap` 与 `stroke-linejoin` 都用 `round`；形状用填充 + 同色系深色描边 + 一处白色高光，形成卡通质感而不过度。
- 每个条目一个不同主题的图形，颜色也要拉开。禁止字母头像，禁止所有条目共用同一个文档轮廓（12px 下就是一个空方块，纯噪音）。
- 没有自带图标时：技能用共享的线性 glyph 叠加派生色块，插件用自己的 glyph，不要回落到首字母。

## 动效

- 不要分组的逐个上浮入场（`rise` + 递增 `animation-delay`）。列表直接出现；这类入场在每次进入页面时都会重放，读起来像模板。
- 只保留对操作的反馈：悬浮与聚焦的颜色、背景过渡 130–140ms，缓动 `cubic-bezier(0.22, 1, 0.36, 1)`。
- `prefers-reduced-motion: reduce` 下关掉这些过渡。

## 颜色与 token

- 除身份标外，所有颜色走语义变量（`--v2-text-*`、`--v2-background-*`、`--v2-border-*`、`--v2-overlay-*`），不写死色值、字号和圆角。
- 派生色（没有自带图标的条目）由条目标识哈希得到固定色桶，保证同一实体在不同视图、重启后颜色一致。

## 文案与可访问性

- 所有可见文案走 i18n；中文写在 `zh.ts`，英文是键的来源。
- 整行是 `role="button"` + `tabindex="0"`，支持 Enter 与空格；`aria-label` 要含名称、来源与安装状态。
- 聚焦可见：`focus-visible` 用 2px 描边，不用 `outline: none` 收掉。

## 交付前自查

1. 控件高度都不超过 32px，搜索框不超过 200px 宽。
2. 每个图标的包围盒中心是 (12, 12)。
3. 把图标缩到 24px 看一遍，图形仍然可辨、彼此不相似。
4. 页面里没有任何入场动画。
5. 没有任何写死的颜色或字号，身份标除外。
6. 所有文案都有 i18n 键，中文已补。
7. 行可以用键盘操作，读屏能听到名称、来源与状态。
