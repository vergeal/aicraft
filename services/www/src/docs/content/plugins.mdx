title: "Plugins"
---

Add published packages, versioned packages, scoped packages, or local plugin directories to `aicraft.json(c)`.

## Configure

```jsonc title="aicraft.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "aicraft-acme-plugin",
    "aicraft-acme-plugin@1.2.0",
    "@acme/aicraft-plugin",
    "./plugins/local",
    "../shared/plugin",
    "/absolute/path/plugin",
    "file:///home/me/plugins/local",
    {
      "package": "@acme/aicraft-plugin",
      "options": {
        "agent": "reviewer",
        "strict": true,
      },
    },
  ],
}
```

Relative paths resolve from the config file containing the entry.

Configured local paths must be directories. A path to a single file is skipped. See [Load](/build/plugins#load) for
how AI Craft finds each part in a directory.

Plugin arrays from applicable config files are applied from lowest to highest precedence instead of replacing one
another.

```text
~/.config/aicraft/aicraft.jsonc
./aicraft.jsonc
./.aicraft/aicraft.jsonc
```

## Discover

AI Craft also loads direct `.ts` and `.js` files and immediate plugin package directories from every discovered
`.aicraft/plugins/` directory.

```text
.aicraft/
└── plugins/
    ├── concise.ts
    ├── reviewer.js
    └── acme-package/
```

Global plugins use the same discovery layout under the AI Craft config directory.

```text
~/.config/aicraft/plugins/
```

A `plugins/` directory beside a project-root `aicraft.json(c)` is not discovered automatically; configure its plugin
directories explicitly or move it under `.aicraft/`.

```jsonc title="aicraft.jsonc"
{
  "plugins": ["./plugins/local"]
}
```

## Control

Plugin entries are processed in order. Prefix an ID or wildcard with `-` to disable it, use `*` for every plugin, and
use `.*` to match an ID prefix. A later ID re-enables a plugin.

```jsonc title="aicraft.jsonc"
{
  "plugins": ["*", "-aicraft.provider.*", "aicraft.provider.openai", "-acme.reviewer"]
}
```

Two built-in plugins ignore removals so that a repository cannot switch off
[policy](/policies) enforcement: `aicraft.config.policy` and
`aicraft.provider.aicraft`, the Console connection that delivers organization
policy.

## Manage

Install, list, check, update, or remove global package plugins with the CLI.

```sh
aicraft plugin add aicraft-acme-plugin@1.2.0
aicraft plugin list
aicraft plugin list --builtin
aicraft plugin check
aicraft plugin update
aicraft plugin update aicraft-acme-plugin
aicraft plugin remove aicraft-acme-plugin@1.2.0
```

`plugin check` checks server, GUI-only, and TUI-only package plugins for updates. `plugin update` updates every outdated package;
pass a configured package target to check or update only that package. Local plugins and exact package revisions are
skipped.

Package installation accepts npm names with versions, tags, or ranges, plus npm-compatible Git package specifications.
Git repositories can use hosted shortcuts, HTTPS, or SSH, including private repositories available through your existing
Git credentials.

```sh
aicraft plugin add @acme/aicraft-plugin@latest
aicraft plugin add github:acme/aicraft-plugin
aicraft plugin add git+ssh://git@github.com/acme/aicraft-plugin.git#main
aicraft plugin add 'github:acme/plugins#main::path:packages/aicraft-plugin'
```

Branches, tags, complete commit hashes, and npm's `::path:` repository-subdirectory selectors are supported. Configure
local paths directly; tarball and npm alias targets are not accepted by `plugin add`.

## Reload

Changes under watched config directories reload automatically. Server startup loads cached package plugins immediately,
installs missing packages in the background, and checks unpinned npm and Git plugins for updates without changing the
installed package. Exact npm versions and full Git commit hashes stay pinned. Changes to unwatched local dependencies
may still require restarting AI Craft.

```sh
touch .aicraft/plugins/concise/index.ts
aicraft service restart
```

## Desktop

A plugin that exports `./gui-experimental` also adds panels, commands, or settings to AI Craft Desktop. The app loads
plugins from the server it runs, so configure the plugin in your global `aicraft.json(c)` to use it in every window.

```jsonc title="~/.config/aicraft/aicraft.jsonc"
{
  "plugins": ["aicraft-acme-plugin"],
}
```

**Settings > Extensions > Plugins** lists them when the app's own server is selected. A plugin's switch turns off only
its desktop UI, and **Reload** loads it again after a failure. To turn off the whole plugin, add `-` and its ID to
`plugins`, for example `"-acme"`.

## Terminal

TUI-only plugins are configured separately and remain active when connected to a remote server.

```json title="cli.json"
{
  "plugins": ["aicraft-acme-cli"]
}
```
