# 17 · 数据可视化

## 1. 语义色板

素材里的图表色只有三支，且**深浅主题取同值**：

| token | 值 | 含义 |
|---|---|---|
| `chart-messages` | `rgb(96,165,250)` 蓝 | 消息 / 请求 |
| `chart-system` | `rgb(173,178,184)` 灰 | 系统 / 后台 |
| `chart-tools` | `rgb(167,139,250)` 紫 | 工具调用 |

深浅同值说明三支颜色在两套背景上**都已满足 3:1**——这是把图表色单独管理、不随主题漂移的正确做法。

### 扩展序列

单一序列不够时按此顺序增加，不要随手取色：

```
1  chart-messages  蓝     主序列
2  chart-tools     紫     次级
3  chart-system    灰     背景/基线
4  state-success   绿     正向
5  state-warn      琥珀   告警
6  state-error     红     异常
```

**超过 6 类时改图形**（分组、小倍数图、堆叠），不要继续加颜色。人眼同时区分的色相上限约 6–8。

## 2. 色彩使用

| 规则 | 说明 |
|---|---|
| 同一序列全图同色 | 不要按数值深浅渐变，除非表达"量"本身 |
| 状态色语义固定 | 绿=成功、红=错误、琥珀=警告，不可挪用 |
| 不只靠颜色编码 | 必须叠加形状/图案/直接标注（色觉障碍） |
| 网格线最弱 | `border-subtle`，0.5px；不要用实线深灰 |
| 坐标轴文字 | 11–12px，`label-tertiary`；不旋转除非必要 |

## 3. 图形选择

| 数据意图 | 图形 | 避免 |
|---|---|---|
| 趋势（时间序列） | 折线 / 面积 | 饼图 |
| 类别比较 | 横向条形（类别多）/ 纵向柱 | 3D 柱 |
| 占比（≤5 类） | 堆叠条 / 环图 | 多环嵌套 |
| 分布 | 直方图 / 箱线 | 折线 |
| 相关性 | 散点 | 双轴折线 |
| 单值进度 | 进度条 / 环形 | 仪表盘 |

**双 Y 轴是最后手段**：两轴刻度可任意调整，容易制造虚假相关。必须用时，两轴各自标注单位与颜色。

## 4. 尺寸与留白

| 项 | 值 |
|---|---|
| 图表内边距 | 上 8 / 右 12 / 下 24（给轴标签）/ 左 40（给刻度） |
| 刻度密度 | 水平 4–6 个，垂直 3–5 个 |
| 柱宽 | 类别间隙 = 柱宽 × 0.4–0.6 |
| 折线粗细 | 2px；数据点 3px，超过 30 点时隐藏点 |
| 图例位置 | 顶部左对齐，或直接标注在线尾 |
| 图表最小高 | 120（微型）/ 240（常规）/ 320（详情） |

## 5. 交互

| 交互 | 规格 |
|---|---|
| Hover | 十字准线 + tooltip（数值 + 类别 + 时间） |
| Tooltip | 深色底（同 Toast），12/18，不超过 3 行 |
| 区间选择 | 拖拽缩放，右下角"重置" |
| 点击 | 下钻到明细表，保持筛选上下文 |
| 键盘 | ←→ 移动数据点，读数用 `aria-live` 播报 |

## 6. 状态

| 状态 | 表现 |
|---|---|
| 无数据 | 坐标轴保留 + 居中"暂无数据"（13px `label-tertiary`） |
| 加载 | 骨架条（用 `bg-skeleton`），不要空坐标系 |
| 单点数据 | 画点不画线，避免"一条直线"误导 |
| 数据异常 | 断点不连线（`connectNulls: false`），标注缺口 |
| 错误 | 说明 + 重试，不画空图 |

## 7. 可访问性

每张图必须提供一个**等价的文本/表格替代**：

- 图下方提供"查看数据表"切换；
- 图表容器 `role="img"` + `aria-label` 概括结论（不是罗列数字）；
- 关键数值用文字直接标注在图上，不依赖 tooltip。

## 8. 性能

| 数据量 | 策略 |
|---|---|
| < 500 点 | 直接渲染 |
| 500–5000 | 抽样/聚合到像素宽度 |
| > 5000 | 服务端聚合，前端只画结果 |
| 实时流 | 固定时间窗 + 逐帧合并，不要每帧重绘全量 |
| 动画 | 首次渲染可播 300ms 入场；刷新不重播 |

## 9. 落地规则

1. 序列色只用语义 token，深浅主题同值。
2. 超过 6 类改图形，不加颜色。
3. 颜色不可作为唯一编码，必须叠加形状或直接标注。
4. 网格线 0.5px 且最弱；双 Y 轴尽量避免。
5. 每张图有数据表替代与一句话结论。
6. 大数据先聚合再渲染，刷新不重播入场动画。
