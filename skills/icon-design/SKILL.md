# 图标设计

这是为技能、插件和条目设计身份标的规范。目标很小：一个 24px 的方形图标，缩到一半还能被认出来，放在一排里彼此不混淆。

## 画布与尺寸

- 画布固定 `viewBox="0 0 24 24"`，不要用别的尺寸再缩放。
- 底色是一个铺满的 `rect`：`width="24" height="24" rx="7"`。圆角是身份标的一部分，不要去掉。
- 在列表里它铺满 40×40，外层容器 `border-radius: 10px; overflow: hidden` 会把底色圆角裁到 10px。不要给图标加内边距或内缩，也不要在外面再套一层背景。
- 预览时同时看 96px、40px、24px 三档。只在 96px 好看、24px 糊掉的图标等于没做。

## 居中

- 图形的包围盒中心必须落在 `(12, 12)`。分别算 `(minX + maxX) / 2` 和 `(minY + maxY) / 2`，两轴都要对。
- 偏 0.5 像素在 24px 下就能看出来。视觉重心比几何中心更容易偏，所以把描边、投影都算进包围盒。
- 一个图标只有一个视觉主体。主体偏了，整排图标就会显得歪。

## 形状语言

- 只用直线、圆、椭圆和对称弧。**不要手写自由贝塞尔曲线**：缩小后边缘一定糊，这是「像小学生画的」最常见来源。
- 形状的角要圆：用 `rx`，或给描边加 `stroke-linejoin="round"`。尖角造型靠加粗描边带出圆润感。
- 线宽 1.2–1.6，`stroke-linecap` 和 `stroke-linejoin` 都用 `round`。
- 卡通感来自四件事：圆润的轮廓、明亮的底色、少量细节、一个一眼能读出的主体。它不来自渐变、投影、噪点或高光堆叠。
- 一个可复用的做法：主体填充 + 同色系深色描边 + 一处白色或浅色高光。这三层就够，不要更多。

## 配色

- 底色是身份内容，可以写死色值；界面其它颜色仍走语义变量。
- 每个条目一个不同色相，也要一个不同图形。同色系里靠明度拉开，不要用两个几乎一样的蓝。
- 避免灰底配灰图：低对比在 24px 下会直接消失，这是最容易犯的错。
- 深色界面里，底色比主体暗一档更容易读；浅色界面里反过来。

## 可读性

- 一个图标只讲一件事。细节控制在 3–4 个形状以内。
- 缩到 24px 自查：主体还能认出来吗？两个图标并排，能一眼区分吗？
- 如果必须靠内部细线才能看懂，说明这个造型选错了，换一个更简单的物体。

## 常见错误

- 用首字母或文字当图标。它不是身份标，只是占位。
- 所有条目共用一个文档轮廓，只在颜色上区分。12px 下就是一个空方块，纯噪音。
- 手写曲线画插画，细节在缩小后全部丢掉。
- 视觉重心偏移，整排看过去高低不齐。
- 灰底灰图，或者主体和底色明度太接近。
- 把渐变、阴影、内发光全叠上，24px 下变成一团脏色。

## 流程

1. 先定这个条目「是什么」，选一个能被一眼读出的物体，而不是抽象概念。
2. 用几何拼出来：底色 → 主体 → 一处细节 → 一处高光。
3. 算包围盒，把中心校到 (12, 12)。
4. 缩到 24px 看一遍，再和已有的图标并排比较色相与形状。
5. 放进 96/40/24 三档的预览页确认，再交付。
