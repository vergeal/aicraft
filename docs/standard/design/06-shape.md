# 06 · 圆角、形状与嵌套

## 1. 圆角阶梯

| 值 | 令牌 | 用途 | 禁止用于 |
| --- | --- | --- | --- |
| 4px | `--radius-xs` | 极小标记、状态点容器、内嵌小标签 | 按钮、卡片 |
| 6px | `--radius-sm` | 输入框、小按钮、分段控件、行内代码 | 大面板 |
| 8px | `--radius-md` | 缩略图、小卡片、下拉项 | 全屏容器 |
| 12px | `--radius-lg` / `--radius-popover` | 卡片、菜单、Popover、默认面板 | 单行输入（应用胶囊） |
| 16px | `--radius-xl` | 大卡片、Toast、内嵌浮层 | 主弹窗 |
| 20px | — | 多行 composer（有附件 / 多行） | 普通卡片 |
| 24px | — | 弹窗、单行 composer 展开后的静止态 | 表格 |
| 28px | — | 大面板、设置分组容器 | 控件 |
| 999px | capsule | 单行输入、标签、头像、状态点、选中药丸 | 多行容器 |

规则：

1. 圆角只用上表值，禁止 10、14、18、22、26 等中间值。
2. 控件圆角与高度联动：**控件高 ≈ 2.5–3 倍圆角**。28px 高 → 10px 理论值，但系统只允许 8 或 6，取 6（输入）或 8（按钮）。
3. 同一屏内圆角档位不超过 3 种。
4. 贴边的面板（侧栏、右侧抽屉、工作区）圆角为 0，不套外壳圆角。

## 2. 何时用胶囊

胶囊（`999px`）是强语义形状，只在同时满足以下条件时使用：

1. **单行**：内容不会换行。
2. **高度 ≤ 40px**。
3. **可数**：它在界面上是"一个标记"或"一个可点的药丸"，不是一块区域。

允许的胶囊场景（白名单）：

| 场景 | 说明 |
| --- | --- |
| 标签 / Tag | 分类、状态、模型名 |
| 头像 | 圆形头像、项目色块（`50%`） |
| 状态点 | 在线、未读、进度点 |
| 单行输入框 | composer 只有一行且无附件时 |
| 选中药丸 | 标签页当前项、分段控件指示器（内层 6–7px，不是胶囊） |
| 计数徽标 | 未读数、角标 |
| 开关轨道 | 24×16，圆角 8（自体胶囊） |

禁止的胶囊场景：

- 多行输入框、带附件的 composer。
- 卡片、面板、弹窗。
- 高 > 40px 的按钮（用 12–16px 圆角）。
- 表格、列表行。
- 整块导航项。

判断口诀：**"它是不是一行字？"** 不是，就不要胶囊。

## 3. 同心圆角

嵌套时内层圆角 = 外层圆角 − 内边距，保证两条边视觉平行：

```
inner-radius = outer-radius − padding
```

示例：外层 12px 卡片、内边距 8px → 内层元素圆角 4px。

规则：

- 差值小于 4px 时，内层直接直角（避免出现 1–2px 的"假圆角"）。
- 卡片内不再放卡片；必须嵌套时，内层必须比外层小至少 4px。
- 输入框内的附件缩略图：外层 12，内缩 6，缩略图 6。

## 4. 特殊形状

| 元素 | 形状 | 理由 |
| --- | --- | --- |
| 用户头像 | `50%` | 人的身份，圆形是通用语言 |
| 项目 / 插件图标容器 | 22% 圆角（40px 容器 → 10px） | 接近 macOS 图标语言 |
| 品牌 mark | 由品牌资产决定 | 不参与界面圆角规则 |
| 选中指示条（侧栏） | 2px 宽，`999px` | 只标记边缘，不构成形状 |
| 分段控件指示器 | 内层 6–7px | 与外轨 8px 同心 |
| 开关 | 轨道 24×16 圆角 8；滑块 12 圆 | 轨道本身就是胶囊 |

## 5. 超椭圆

若平台支持 `corner-shape: superellipse(1.5)`，可用于 12px 以上的卡片与面板，使边缘更接近 macOS 图标语言。

强制例外：

```css
.pill, .avatar, .status-dot {
  corner-shape: round;
}
```

所有胶囊与圆形必须显式退出超椭圆，否则会变成"方角椭圆"，这是最明显的翻车点。

不支持 `corner-shape` 的引擎自动回退圆弧，不需要 JS 探测。

## 6. 描边与圆角的关系

- 0.5px 描边使用 `inset box-shadow` 绘制，跟随圆角，不占布局。
- 描边不能用 `border` 加在需要精确圆角的元素上（会被抗锯齿裁切）。
- 需要"透明占位边框"时：`border: 0.5px solid transparent` + inset shadow。

```css
.surface {
  border-radius: 12px;
  box-shadow: inset 0 0 0 0.5px var(--v2-border-border-base);
}
```

## 7. 图标圆角

- 线性图标本身不设圆角。
- 图标容器（40×40）用 10px（22%）。
- 小图标容器（24×24）用 6px。
- 禁止给图标容器用胶囊（会看起来像按钮）。

## 8. 禁止

- 同一元素上混用不同圆角（例如 top 24 / bottom 8）——唯一例外是消息气泡的尖角一侧。
- 用圆角表达层级（层级用阴影与材质）。
- 圆形按钮里放方形图标容器。
- 胶囊内再套胶囊。
- 给全屏区域加圆角，然后在外面留一条背景色（会出现"悬浮卡片"错觉）。
