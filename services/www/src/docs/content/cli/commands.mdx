---
title: "Commands"
description: "Reference for the aicraft command line."
---

Every command accepts `--help` for its full flag list, for example `aicraft run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ aicraft run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Aicraft review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @aicraft/cli
      - run: aicraft run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ aicraft run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ aicraft run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ aicraft run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ aicraft run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ aicraft run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ aicraft run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ aicraft run --auto "Fix the failing test"
```

Create the session archived so scripted or CI runs stay out of session lists and the inbox. The session still exists: `aicraft session list` includes it, and you can open it by ID.

```bash
$ aicraft run --archived "Review this diff"
```

View all subcommands and flags.

```bash
$ aicraft run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ aicraft mini
```

Continue the last session.

```bash
$ aicraft mini --continue
```

Start with a model and an initial prompt.

```bash
$ aicraft mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ aicraft mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ aicraft mini --help
```

## session

Manages sessions.

```bash
$ aicraft session list
```

Limit the list and print JSON.

```bash
$ aicraft session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ aicraft session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ aicraft session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ aicraft session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ aicraft session import session.json
```

Import into a specific directory.

```bash
$ aicraft session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ aicraft session --help
```

## auth

Manages AI providers and credentials.

```bash
$ aicraft auth list
```

List them as JSON.

```bash
$ aicraft auth list --format json
```

Log in to a provider.

```bash
$ aicraft auth login anthropic
```

Log in with a specific authentication method.

```bash
$ aicraft auth login anthropic --method key
```

Log out of a saved account.

```bash
$ aicraft auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ aicraft auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ aicraft auth export anthropic > credentials.json
$ aicraft auth import credentials.json
```

View all subcommands and flags.

```bash
$ aicraft auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ aicraft mcp list
```

Add a remote server.

```bash
$ aicraft mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ aicraft mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ aicraft mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ aicraft mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ aicraft mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ aicraft mcp logout sentry
```

View all subcommands and flags.

```bash
$ aicraft mcp --help
```

Manages plugins.


```bash
$ aicraft plugin list --builtin
```



```bash

```

```bash
$ aicraft plugin remove @example/aicraft-tui
```

View all subcommands and flags.

```bash
$ aicraft plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ aicraft serve
```

Bind to all interfaces on a fixed port.

```bash
$ aicraft serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ aicraft serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ aicraft serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ aicraft pair
```

Use an external URL in the links.

```bash
$ aicraft pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ aicraft pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ aicraft pair --remote --yes
```

View all subcommands and flags.

```bash
$ aicraft pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ aicraft service start
```

Restart it.

```bash
$ aicraft service restart
```

Show its status.

```bash
$ aicraft service status
```

Stop it.

```bash
$ aicraft service stop
```

Read a setting.

```bash
$ aicraft service get hostname
```

Set a setting.

```bash
$ aicraft service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ aicraft service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ aicraft service set env AICRAFT_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ aicraft service unset hostname
```

View all subcommands and flags.

```bash
$ aicraft service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ aicraft reload
```

## api

Makes a request to the running server.

```bash
$ aicraft api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ aicraft api session.list --param limit=10
```

Send a JSON body.

```bash
$ aicraft api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ aicraft api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ aicraft api --help
```

```bash
$ aicraft acp
```

```bash
$ aicraft acp --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ aicraft debug agents
```

List configuration sources.

```bash
$ aicraft debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ aicraft debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ aicraft debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ aicraft debug paths
```

Print a single path.

```bash
$ aicraft debug paths db
```

View all subcommands and flags.

```bash
$ aicraft debug --help
```

## upgrade

Upgrades AI Craft to the latest or a specific version. Alias: `update`.

```bash
$ aicraft upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ aicraft upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ aicraft upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls AI Craft. Session data, configuration, and
state are not removed.

```bash
$ aicraft uninstall
```

Preview what would be removed.

```bash
$ aicraft uninstall --dry-run
```

View all subcommands and flags.

```bash
$ aicraft uninstall --help
```
