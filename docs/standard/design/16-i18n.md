# 16 · 国际化与文案

## 1. 必须走 i18n

所有用户可见文字：标题、按钮、菜单、空状态、错误、Toast、Tooltip、placeholder、无障碍标签。

- 文案 key 使用 `模块.场景.含义`，例如 `settings.appearance.theme`。
- 新增 key 时同步补 `zh.ts`（简体中文）与英文源；缺中文即为不合格。
- 不拼接句子。需要变量时使用占位符，`{count} 个文件`，不写 `"共" + n + "个文件"`。
- 计数文案必须处理单复数（英文）。

## 2. 字体栈与 CJK

```css
--font-family-sans:
  ui-sans-serif, system-ui, -apple-system,
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

- 中文回退必须显式声明，禁止依赖系统默认。
- 中文字号与英文同档（14/22），但行高不得低于 1.5 倍。
- 中文不使用斜体、不使用全部大写。

## 3. 断行与排版

| 场景 | 规则 |
| --- | --- |
| 正文 | 允许换行，`text-wrap-style: pretty` |
| 按钮 | 不换行，超出用省略 |
| 标签 / Tag | 不换行 |
| 标题 | 允许两行，超过截断 |
| 表格 | 默认单行省略 |
| 代码 | 不换行，横向滚动 |

- 中英混排不断词，不插入零宽空格。
- 标点使用全角（`，。：；？！`），括号按内容语言选择。
- 数字与单位之间不加空格：`12px`、`50%`、`3 个`。
- 日期 `YYYY-MM-DD`，时间 `HH:mm`；相对时间 ≤ 7 天。

## 4. 文案语气

| 维度 | 我们 | 不要 |
| --- | --- | --- |
| 语气 | 平静、直接、具体 | 热情、夸张、卖萌 |
| 人称 | 对用户说"你" | "您"（过度正式） |
| 动词 | 具体动作 | 泛化动作 |
| 错误 | 原因 + 修法 | 道歉 + 空话 |
| 进行中 | 具体对象 | "请稍候" |

示例：

| 场景 | 合格 | 不合格 |
| --- | --- | --- |
| 空列表 | 还没有项目。新建一个开始吧。 | 空空如也～ |
| 删除确认 | 删除项目「aicraft」？其中的 12 个会话将一并移除，且无法恢复。 | 确定要删除吗？ |
| 错误 | 无法连接到模型服务，请检查网络后重试。 | 出错了！ |
| 保存成功 | 已保存 | 保存成功！！！ |
| 加载 | 正在读取 12 个文件… | 加载中… |

## 5. 长度限制

| 元素 | 上限 |
| --- | --- |
| 页面标题 | 16 字 |
| 按钮 | 6 字 |
| 菜单项 | 8 字 |
| 导航项 | 4 字 |
| 标签 | 8 字 |
| 帮助文字 | 40 字 |
| Toast | 40 字 |
| 空状态说明 | 40 字 |

超出时优先改文案，不缩字号。

## 6. 数字与单位

- 千分位：`1,024`。
- 百分比：`12%`，不写 `12 %`。
- 时间跨度：`2 分钟`、`1 小时 20 分`。
- 文件大小：`1.2 MB`（中间一个空格）。
- 模型名、路径、命令保持原文，不翻译。

## 7. RTL

当前不启用 RTL，但布局禁止写死 `left/right`：

- 使用 `inline-start` / `inline-end` 或逻辑属性。
- 图标翻转仅用于方向性图标（箭头、返回），不翻转语义图标。

## 8. 禁止

- 硬编码中文或英文在组件里。
- 用字符串拼接构造句子。
- 省略号用 `...`（必须 `…`）。
- 用全角括号包裹英文。
- 翻译产品名、命令、路径。
- 同一含义在不同页面用不同词（统一术语表：会话 / 项目 / 工具 / 步骤）。
