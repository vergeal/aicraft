# 04 · 字体排印

## 1. 字体族：只有两类

| 类别 | 令牌 | 字体栈 | 用于 |
| --- | --- | --- | --- |
| 界面与正文 | `--font-family-sans` | `Inter` → `ui-sans-serif` → `system-ui` → `-apple-system` → `PingFang SC` → `Microsoft YaHei` | 所有 UI 文字、对话正文 |
| 等宽 | `--font-family-mono` | `IBM Plex Mono` → `ui-monospace` → `SFMono-Regular` → `Menlo` | 代码、路径、模型名、数字表格 |

规则：

- 只有这两类。**禁止**引入第三类展示字体、书法字体、手写字体。
- 品牌字标（wordmark）属于品牌资产，不受本文限制，但只能出现在启动页与关于页。
- 中文回退必须显式声明，不能依赖系统默认（否则 Windows 会落到宋体）。
- 数字、时间、计数必须加 `font-variant-numeric: tabular-nums`。

## 2. 字号阶梯：六档

| 档 | 字号 | 行高 | 字重 | 字距 | 用途 |
| --- | --- | --- | --- | --- | --- |
| micro | 11px | 16px | 400 | 0 | 时间戳、计数、快捷键、页脚提示 |
| meta | 12px | 18px | 400 / 500 | 0 | 元数据、标签、表格表头、辅助说明 |
| ui | 13px | 20px | 400 / 500 | 0 | 导航项、菜单项、表单标签、按钮小号 |
| body | 14px | 22px | 400 | 0 | 正文、描述、对话内容、按钮默认 |
| title | 18px | 26px | 600 | -0.01em | 面板标题、卡片组标题 |
| display | 20–28px | 28–36px | 600 | -0.02em | 页面主标题、空状态主标题 |

补充约束：

1. 只有这六档。禁止 15 / 16 / 17 / 19 / 21 等中间值。
2. 28px 只用于"首次进入"的空状态主标题，且一屏只能出现一次。
3. 低于 11px 的文字不允许出现在任何界面。
4. 行高必须显式声明，不使用 `normal`。

## 3. 字重：三档

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--font-weight-regular` | 400 | 正文、菜单、表格 |
| `--font-weight-medium` | 500 | 按钮、标签、导航当前项、表头 |
| `--font-weight-bold` | 600 | 标题、强调数字 |

规则：

- 禁止 510 / 550 / 590 这类插值字重（可变字体缺失时会回退）。
- 禁止整段文字使用 600；加粗只用于"这个词是一行的结论"。
- 同一行内最多两种字重。

## 4. 行高

| 字号 | 行高 | 说明 |
| --- | --- | --- |
| 11 | 16 | micro |
| 12 | 18 | meta |
| 13 | 20 | ui |
| 14 | 22 | body（中文正文的最小舒适值） |
| 16 | 26 | 长文阅读 |
| 18 | 26 | 小标题 |
| 20 | 28 | 页面标题 |
| 24–28 | 32–36 | 空状态主标题 |

- 中文行高不得低于字号的 1.5 倍；14px 正文必须 22px。
- 单行控件（按钮、输入框）用固定高度 + `line-height` 居中，不依赖 padding 撑高。
- 多行文本禁止设置固定高度，用 `min-height`。

## 5. 中英混排

- 中英文之间不手动加空格，由字体与 `text-autospace`（支持的引擎）处理。
- 中文不使用斜体。
- 中文标点使用全角，英文与数字使用半角；混排时数字两侧不加空格。
- 破折号用 `——`，连接号用 `-`，省略号用 `…`。
- 代码、路径、快捷键在中文句子中必须使用等宽字体或包裹 `<code>`。

## 6. 数字

- 所有会变化的数字（计数、时间、费用、进度）使用 `tabular-nums`，避免跳动。
- 百分比、货币符号与数字之间不留空格。
- 时间统一 `HH:mm`；日期统一 `YYYY-MM-DD`；相对时间优先（"刚刚""2 分钟前"），超过 7 天转绝对日期。

## 7. 截断与换行

| 场景 | 规则 |
| --- | --- |
| 单行标题、导航项、按钮 | `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`，且父级 `min-width: 0` |
| 两行描述 | `-webkit-line-clamp: 2` |
| 表格单元格 | 默认单行省略；需要换行的列显式声明宽度 |
| 对话正文 | 不截断，允许换行 |
| 代码块 | 横向滚动，不换行（除非用户开启软换行） |

**禁止**：对按钮文字、标签文字使用 `line-clamp`；对正文使用 `nowrap`。

## 8. 标题字距

- 20px 及以上：`letter-spacing: -0.02em`。
- 14–18px：`-0.01em` 或 0。
- 13px 及以下：0。
- 正文禁止负字距。
- 英文全大写标签（如 `NEW`）：`+0.04em`，且只用于 11–12px。

## 9. 光学对齐

- 图标与文字混排时，图标按文字的大写高度居中，不按几何盒居中。
- 数字与图标对齐时使用 `text-box-trim: trim-both`（Chromium 支持）消除行盒上下留白。
- 中文字体与英文字体在同一字号下视觉重量不同，混排段落必须以实际渲染结果校准，不能只看设计稿。

## 10. 禁止

- 使用 15 / 16 / 17 / 19 / 21 / 22px 等阶梯外字号。
- 使用除 400 / 500 / 600 之外的字重。
- 对正文设置负字距或 `text-transform: uppercase`。
- 用字号大小表达"重要"（重要应通过位置、字重、留白表达）。
- 在按钮内使用 400 字重。
