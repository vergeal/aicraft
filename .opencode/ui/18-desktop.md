# 18 · 桌面端适配

## 1. 窗口与标题栏

| 项 | 规格 |
|---|---|
| 窗口圆角 | macOS 由系统给；自绘窗口用 12–16，全屏时归零 |
| 标题栏高 | 38–44（含交通灯） |
| 拖拽区 | `-webkit-app-region: drag` **只加在标题栏容器** |
| 免拖拽区 | 标题栏内所有可点元素（按钮、输入框、链接、页签）必须 `no-drag` |
| 交通灯留白 | macOS 左侧 78–88px 不放内容；其它平台对应右侧 |

素材实测的分布很说明问题：`drag` 只有 2 处、`no-drag` 有 15 处——**默认不拖，只在标题栏开一个口子**。反过来写（整页 drag、逐个补 no-drag）必然漏，最终导致"点按钮拖走了窗口"。

```css
.titlebar { -webkit-app-region: drag; }
.titlebar :where(button, a, input, [role='tab'], [tabindex]) {
  -webkit-app-region: no-drag;
}
```

## 2. 平台差异

素材里 `data-platform='darwin'` 出现 **81 次**，是单点最多的适配钩子。说明：**平台差异用属性一次性标注在 `<html>` 上，不要散落 UA 判断**。

```html
<html data-platform="darwin">
```

| 差异点 | macOS | Windows / Linux |
|---|---|---|
| 交通灯 / 窗口按钮 | 左 | 右 |
| 原生 vibrancy | 支持，但透明浮层合成不可靠 → 菜单改近不透明（0.94） | 不支持，用纯色 |
| 滚动条 | 系统叠加式，可隐藏 | 占位式，需 `scrollbar-gutter` |
| 快捷键符号 | `⌘ ⌥ ⇧` | `Ctrl Alt Shift` |
| 字体 | `-apple-system` / `PingFang SC` | `Segoe UI` / `Microsoft YaHei` |
| 右键菜单 | 系统风格偏好更强 | 可自绘 |

## 3. 滚动条

| 项 | 值 |
|---|---|
| 宽 | 5–6（细） |
| 滑块圆角 | 999 |
| 轨道 | 透明，不画背景 |
| 颜色 | `scrollbar-bg-l1` / `l2`（按表面层级重绑） |
| 悬停 | 提高一档透明度 |
| 留白 | `scrollbar-gutter: stable` 防止内容跳动 |

**两处必须做**：① 浮层（菜单、面板）内的滚动条用 l2 更浅的色；② 滚动条不影响布局宽度，否则内容会随滚动条出现而位移。

## 4. 原生集成

| 能力 | 要点 |
|---|---|
| 原生菜单 | 菜单项文案与界面文案同源，不要手写两份 |
| 托盘 | 点击显示/隐藏主窗口；关闭窗口 ≠ 退出应用（需明确告知） |
| 系统通知 | 仅在窗口未聚焦时发；点击直达对应会话 |
| 文件拖放 | 整个窗口可接收，拖入时高亮投放区；`dragover` 必须 `preventDefault` |
| 协议链接 | `app://` / 自定义 scheme 需在 `open-url` 中处理，且要防止重复打开 |
| 单实例 | 二次启动聚焦已有窗口，不新开进程 |

## 5. 窗口尺寸

| 项 | 建议 |
|---|---|
| 最小宽 | 720（低于此三栏无法成立，转单栏） |
| 最小高 | 560 |
| 默认尺寸 | 1280×800（或屏宽 70%） |
| 尺寸记忆 | 按窗口类型分别记忆，恢复时校验是否仍在可见屏幕内 |
| 全屏 | 隐藏标题栏拖拽区冗余，圆角归零 |
| 多窗口 | 分离窗口（如单独预览）继承主题但独立滚动位置 |

## 6. 高 DPI 与 0.5px

- 0.5px 描边在 2x 屏上渲染为 1 物理像素，正好；在 1x 屏上会被舍入。
- 因此 0.5px 必须用 `inset box-shadow` 或 `outline` 绘制，**不要用 `border`**：`border` 在 1x 下会直接消失或变 1px 抖动。
- 图片资源按 2x 提供；矢量优先。
- 窗口缩放（非整比例）时，用 `devicePixelRatio` 判断是否降级为 1px。

## 7. 系统级偏好

| 偏好 | 处理 |
|---|---|
| 深浅色 | 跟随系统，但允许应用内覆盖；两者都要记住 |
| 减少动效 | `prefers-reduced-motion`，关闭装饰动画 |
| 高对比 | `forced-colors`，主题色让位 |
| 系统字号 | 不直接读系统字号；用应用内字号轴（见 03） |
| 强调色 | 可选跟随系统强调色（macOS），默认不用 |

## 8. 更新与失败

| 场景 | 要求 |
|---|---|
| 检查更新 | 静默，不打断；有新版本时用非模态提示 |
| 下载中 | 进度可见，可后台继续 |
| 重启安装 | 明确说明"将关闭当前窗口"，先落盘未保存内容 |
| 更新失败 | 给出可用版本 + 重试，不静默重试循环 |
| 强制更新 | 只用于安全/协议变更，且必须说明原因 |

## 9. 落地规则

1. 拖拽区只加在标题栏，子元素统一 `no-drag`。
2. 平台差异用 `<html data-platform>`，禁止运行时 UA 判断散落。
3. 透明浮层在 macOS 需降级为近不透明。
4. 滚动条不占布局（`scrollbar-gutter: stable`），浮层用更浅一档。
5. 0.5px 用 box-shadow/outline，不用 border。
6. 最小窗口 720×560，低于则转单栏。
7. 关闭窗口行为要明确（隐藏 or 退出），并在首次关闭时告知。
