2会话行 64

头像 40、名字 14/20、预览 12/18、时间与未读在右侧。选中行同时给淡强调底和左缘 2px 指示条。

3彩色只用于身份与状态

头像块、未读、公告、发送是整页仅有的彩色；气泡、列表、卡片全部走中性层，深浅主题同一套变量。

4消息列 760

5消息里的富对象

文件卡、状态卡是气泡内的子卡：圆角 8 = 外层 12 − 内缩，白底 + 输入级阴影，与气泡拉开一层。

6输入区

卡片高 88、圆角 16：上排 28 工具图标，下排输入 + 快捷键提示 + 36 发送。空内容时发送降到 28% 并禁用。
