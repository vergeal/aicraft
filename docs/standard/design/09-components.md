# 09 · 组件规范

每个组件只允许出现下列尺寸与状态。未列出的变体，先补规范再实现。

## 1. 按钮

| 尺寸 | 高 | 水平内边距 | 字号 | 圆角 |
| --- | --- | --- | --- | --- |
| small | 24 | 8 | 12 | 6 |
| default | 28 | 10 | 13 | 6 |
| medium | 32 | 12 | 13 | 8 |
| large | 36 | 16 | 14 | 8 |

变体（只有四种）：

| 变体 | 底 | 文字 | 边框 | 用途 |
| --- | --- | --- | --- | --- |
| primary | 黑白对（`bg-contrast`） | 反色 | 无 | 页面唯一主要操作 |
| secondary | `bg-button-neutral` | 主文字 | 0.5px `border-base` | 次要操作 |
| ghost | 透明 | 次文字 | 无 | 工具栏、行内操作 |
| danger | 透明 / 危险底 | 危险色 | 危险边框 | 删除、不可恢复 |

状态：default / hover / pressed / focus-visible / disabled / loading。

规则：

- 一屏只能有一个 primary。
- 按钮内图标 14–16px，图标与文字间距 6。
- 纯图标按钮：28×28 容器，圆角 6。
- 禁用使用 `opacity: .4` + `disabled`，不允许只改颜色。
- loading 时保留原宽度，文字替换为 12px 指示器，避免跳动。

## 2. 输入框

| 类型 | 高 | 圆角 | 字号 | 内边距 |
| --- | --- | --- | --- | --- |
| 单行 | 28（紧凑 24 / 表单 32） | 6 | 13 | 左右 8 |
| 多行 | 最小 72 | 8 | 13 / 行高 20 | 8 |
| 内嵌（搜索） | 28 | 6 | 13 | 左 28（图标位） |

状态：

| 状态 | 表现 |
| --- | --- |
| default | `bg-base` + `elevation-input` + 透明 outline |
| hover | outline `border-strong` |
| focus | outline 1px `border-focus` + 2px 外环（低透明度） |
| error | 1px 危险边框 + 错误文字 |
| disabled | `bg-deep` + 弱文字，禁止光标 |

规则：

- 输入框宽度默认 280，表单中可 100%（最大 420）。
- placeholder 使用 `text-faint`，不得作为唯一标签。
- 多行输入右下角不允许放 resize 手柄（桌面端）。
- 输入框内不要放主按钮（composer 例外，见第 13 节）。

## 3. 选择器

- Select：高 28，圆角 6，右侧 12px chevron，弹层为菜单（高 30 行）。
- Combobox / 搜索选择：输入框 + 下方浮层，浮层最大高 320，超出滚动。
- 单选 / 复选：18×18，圆角 4（复选）/ 50%（单选），选中为强调色底 + 白色勾。
- 开关：24×16，轨道圆角 8，滑块 12，过渡 120ms。

分组选择（多选一、2–4 个选项）用分段控件，不用单选按钮。

## 4. 分段控件

- 高 28，外轨圆角 8，内指示器圆角 6。
- 每段水平内边距 12，字号 13 / 500。
- 指示器用 `transform: translateX` 移动，160ms。
- 段数 2–4；超过 4 个改用标签页或下拉。

## 5. 标签页

- 条高 52（顶栏齐平时 48），标签高 32。
- 当前项：底部 2px 指示线 或 胶囊底（二选一，同一产品内统一）。
- 标签文字 13 / 500；未选 400 / 次色。
- 标签数量超过 6 个时允许横向滚动；禁止换行。

## 6. 菜单

| 项 | 值 |
| --- | --- |
| 最小宽 | 160 |
| 内边距 | 4 |
| 项高 | 30 |
| 项内边距 | 0 8 |
| 圆角 | 12（外）/ 6（项） |
| 字号 | 14 |
| 材质 | 玻璃 `blur(20px)` |

- 项内结构：图标 16 + 标签 + 右侧快捷键（11px 弱色）。
- 分组用 1px 分隔线（上下 4px 间距），不用分组标题。
- 危险项放在最后，分隔线之下。
- 菜单最大高 360，超出滚动。

## 7. 弹窗

| 项 | 值 |
| --- | --- |
| 宽 | 480（large 640，最大 760） |
| 圆角 | 24 |
| 内边距 | 24 |
| 标题 | 18 / 26 / 600 |
| 说明 | 14 / 22 / 次色 |
| 按钮区 | 右下，间距 8，高 32 |
| 遮罩 | 黑 40% + `blur(6px)` |
| 阴影 | `elevation-overlay` |
| 材质 | `material-surface-strong` + `blur(40px)` |

结构：

```
标题
说明（可选）
──────────
内容（表单 / 列表，可滚动，最大高 = 视口 - 48 - 头部 - 按钮区）
──────────
[取消] [主操作]
```

规则：

- 只允许一个主操作。
- 危险操作的主按钮使用危险色，且文案写清动作（"删除项目"，不是"确定"）。
- 打开时焦点进入第一个可交互元素；关闭后焦点回到触发元素。
- 内容超过 3 个字段改用页面或抽屉。

## 8. 抽屉 / 右侧面板

- 宽 `clamp(320px, 34vw, 560px)`，贴右边缘，圆角 0。
- 头部 48 与顶栏对齐：标题 13 / 500 + 关闭按钮 28。
- 内容区独立滚动，底部操作条吸底 56。
- 打开动画 `translateX(12px) + opacity`，220ms；不做整块滑入遮挡会话。

## 9. Toast

| 项 | 值 |
| --- | --- |
| 宽 | 320（最大 `100vw - 64`） |
| 圆角 | 16 |
| 内边距 | 12 |
| 字号 | 13 / 20 |
| 位置 | 右下，距边 16，多个垂直堆叠 8 |
| 停留 | 4s（错误 8s，可手动关闭） |

- 只用于异步结果，不用于表单校验。
- 同一时刻最多 3 个，超出替换最旧。
- 错误 Toast 必须带一个操作。

## 10. Tooltip

- 反相实色底（深色浅底 / 浅色深底），白/黑字，11–12px。
- 圆角 6，内边距 4 8，最大宽 240。
- 延迟 400ms 出现，150ms 淡入，移出立即消失。
- 只补充信息，不承载操作。
- 禁止在触摸设备上依赖 Tooltip。

## 11. 标签、徽标、头像

| 元素 | 高 | 圆角 | 字号 | 说明 |
| --- | --- | --- | --- | --- |
| Tag | 20 | 999 | 11 / 500 | 分类、模型名；底色 `bg-layer-02` |
| Badge | 16 | 999 | 10–11 | 计数，最多 2 位，超出 99+ |
| 状态点 | 6–8 | 50% | — | 只表示状态，必须配文字 |
| 头像 | 24 / 28 / 32 / 40 | 50% | 按尺寸 | 无图时用首字，字号 = 尺寸 × 0.42 |

Tag 不使用状态色（除危险标签），不使用彩色边框。

## 12. 卡片

- 圆角 12，0.5px 描边，内边距 16，无阴影。
- 可点击卡片：hover 背景提一档 + 描边提一档，不做位移超过 2px。
- 卡片内只允许一个主操作；其余用 ghost。
- 禁止卡片套卡片；必须嵌套时内层圆角 = 外层 − 内边距。

## 13. Composer（AI 输入区）

| 状态 | 高 | 圆角 | 说明 |
| --- | --- | --- | --- |
| 单行 | 48–56 | 24（胶囊感） | 只有一行文字、无附件 |
| 默认 | 88 | 20 | 输入 + 工具栏两行 |
| 展开 | 最大 336 | 20 | 内部滚动 |
| 生成中 | 同展开 | 20 | 发送变停止 |

- 宽度与会话内容列一致（650），不额外加宽。
- 内部结构：附件区（有才显示）→ 输入区 → 工具栏 36。
- 发送按钮 36×36，圆角 12，黑白对；空输入时 `opacity .28` 且禁用。
- focus 时只改变描边与一圈低透明度光，不放大、不上浮。
- 生成中显示停止按钮，输入区仍可编辑（可追加指令）。

## 14. 列表行

| 场景 | 高 | 内边距 | 圆角 |
| --- | --- | --- | --- |
| 导航会话行 | 29 | 0 10 | 6 |
| 设置项 | 44–48 | 0 12 | 8 |
| 菜单项 | 30 | 0 8 | 6 |
| 结果行 | 36–44 | 0 12 | 8 |

- hover 用 4% 覆盖层；选中用 `bg-layer-02` 或 `color-selected`。
- 行尾元信息 11px 弱色，右对齐。
- 行内操作默认隐藏，hover 或 focus 时显示，且不改变行宽。

## 15. 表格

- 表头 12 / 500 / 次色，行高 32，单元格左右内边距 12。
- 分隔线只用 1px 底边（`border-muted`），不画竖线。
- 数字右对齐 + `tabular-nums`；文本左对齐。
- 排序指示 12px，置表头文字右侧 4px。
- 空表格显示空状态行（高 120），不显示"暂无数据"裸文本。
- 宽表允许横向滚动，首列可吸附。

## 16. 空状态

```
[图标或品牌 mark，24–32，弱色]
标题 18–20 / 600
说明 14 / 次色，最多两行
[主操作]（最多 1 个）
```

- 上下留白 40。
- 不使用大插画、不使用营销文案。
- 空状态必须能承接"下一步"（按钮或快捷入口）。

## 17. 骨架与进度

- 骨架块圆角 4–8，底色 `bg-skeleton`。
- 闪烁 1.5s ease-in-out，`prefers-reduced-motion` 时静止。
- 加载超过 400ms 才显示骨架；短于 400ms 直接呈现结果。
- 进度条高 4，圆角 999；不确定进度用 1.2s 循环的 30% 宽度条。

## 18. 图表

- 图表色板最多 3 色：`--c-chart-1/2/3`（蓝 / 紫 / 灰），不随主题漂移。
- 同一图表内不得超过 3 个数据系列；更多系列合并为"其他"。
- 坐标轴与网格线用 `border-muted`；网格线只画横向。
- 数字使用 12/18，`tabular-nums`；轴标签 11/16。
- 交互：hover 显示十字准线 + Tooltip；不画阴影、不做 3D。
- 无数据时显示空状态（高 120），不渲染空坐标系。
- 禁止饼图超过 4 块，禁止彩虹色板。

## 19. 组件通用规则

1. 所有可交互组件必须有 default / hover / pressed / focus-visible / disabled 五态。
2. 状态由 `data-state` / `aria-*` 驱动。
3. 所有组件继承字号与颜色令牌，不允许组件内重定义基础排版。
4. 组件的最小点击区 28×28。
5. 组件不得自带外边距；间距由父级布局决定。
