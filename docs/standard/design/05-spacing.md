# 05 · 间距与尺寸

## 1. 基准

- 基准单位 4px（`--spacing`）。
- 允许的间距值只有：**2、4、6、8、12、16、20、24、32、40、48**。
- 4 的倍数之外只有 2 和 6 两个例外，用于图标与文字、极密排列。
- 禁止 5、7、10、14、18、22、26、28、30 等值（28 仅作为控件高度档位存在，不作间距）。

## 2. 间距阶梯与语义

| 值 | 名称 | 用途 |
| --- | --- | --- |
| 2 | hairline | 行与行之间的最小缝、分段控件内边距 |
| 4 | tight | 图标与文字、标签内左右 |
| 6 | snug | 输入框内文字与图标、按钮组间隙 |
| 8 | inline | 同一行元素之间、卡片内小间距 |
| 12 | list | 列表行内水平内边距、卡片内边距（小） |
| 16 | block | 卡片内边距、表单行之间 |
| 20 | section | 区块标题与内容之间 |
| 24 | region | 大区块之间、设置分组之间 |
| 32 | page | 页面内边距、标题组与主体之间 |
| 40 | hero | 空状态上下留白 |
| 48 | max | 窗口级最大留白 |

规则：**同一层级只用同一档**。不要在同一个列表里出现 8 和 12 两种行内边距。

## 3. 控件高度阶梯

| 高度 | 用途 |
| --- | --- |
| 20 | 极小标签、状态点（非交互） |
| 24 | 密集表格内按钮、行内图标按钮 |
| 28 | 输入框、选择器、小按钮、菜单项、分段控件 |
| 32 | 默认按钮、表单主操作、标签页触发器 |
| 36 | 主要 CTA、工具栏主按钮 |
| 40 | 大号 CTA、空状态入口 |
| 44 / 48 | 触摸或演示场景 |

规则：

1. 输入框默认 28；对话框内可升到 32；表单页主输入允许 32。
2. 按钮与相邻输入框高度必须相等（同一行内）。
3. 相邻控件高度差只能是相邻档（28→32）或隔一档（28→36）。
4. 高度必须是上表值；禁止 35、30、26 等。

## 4. 行高节奏

| 场景 | 行高 | 说明 |
| --- | --- | --- |
| 侧栏会话行 | 29px | 密，可滚动 |
| 侧栏项目行 | 30px | 带展开箭头 |
| 菜单项 | 30px | 内边距 0 8 |
| 表格行 | 28–36px | 默认 32 |
| 设置项 | 40–48px | 标签 + 控件 |
| 消息之间 | 18–24px | 同组 4 |
| 表单字段之间 | 20px | 标签 + 控件 + 帮助 |
| 表单分组之间 | 32px | 带分组标题时 24 |

## 5. 页面留白

| 位置 | 值 |
| --- | --- |
| 窗口内容区左右内边距 | 20–24px |
| 页面顶部到第一个标题 | 32–40px |
| 内容列最大宽度 | 650 / 760 / 820（按页型） |
| 内容列与窗口边缘最小间距 | 24px |
| 空状态主体上下留白 | 40–48px |
| 底部与输入区 | 20–28px |

内容列必须居中；窗口变宽时增加两侧留白，不拉宽正文（超过 820px 的正文不可读）。

## 6. 组内与组间

这是最容易做乱的地方，按"关系越近，间距越小"处理：

| 关系 | 间距 |
| --- | --- |
| 标签 ↔ 输入框 | 6 |
| 输入框 ↔ 帮助文字 | 6 |
| 输入框 ↔ 错误文字 | 6 |
| 同一字段组内的字段 | 16 |
| 不同字段组 | 32 |
| 分组标题 ↔ 第一项 | 12 |
| 列表项之间 | 2（密）/ 8（疏） |
| 卡片之间 | 12 |
| 页面标题 ↔ 副标题 | 10 |
| 标题组 ↔ 主体 | 24–32 |

**禁止**：用 margin 同时表达"组内"和"组间"；必须显式设置，不允许依赖默认外边距。

## 7. 图标间距

| 场景 | 间距 |
| --- | --- |
| 图标 ↔ 文字（按钮、菜单） | 6 |
| 图标 ↔ 文字（导航项） | 10 |
| 图标 ↔ 文字（提示条） | 8 |
| 图标按钮内的图标尺寸 | 16（容器 28） |

## 8. 触达区域

- 任何可点击元素的命中区域不小于 **28×28px**。
- 图标按钮视觉可以 16px，但必须用 padding 或伪元素补到 28×28。
- 相邻可点击元素之间至少留 4px，避免误触。

## 9. 响应式尺寸

| 窗口宽度 | 行为 |
| --- | --- |
| ≥ 1200 | 三栏完整：280 / 自适应 / 320–560 |
| 1000–1200 | 侧栏 240，内容列保持 |
| 768–1000 | 侧栏折叠为 56 图标列 |
| < 768 | 侧栏抽屉化，右侧面板覆盖式 |

窗口变窄时**先减留白，再减栏宽，最后才缩字号**；字号在任何宽度下不变。

## 10. 密度

只允许两档，通过 `data-density` 切换；默认 `comfortable`。

| 项 | comfortable | compact |
| --- | --- | --- |
| 控件高 | 28 | 24 |
| 表格行高 | 32 | 28 |
| 列表行高 | 36 | 28 |
| 区块间距 | 16 | 12 |
| 圆角 | 8 | 6 |

规则：

- compact 只用于数据密集的表格与文件树，不用于表单、设置、页面头。
- 同一屏内不允许混用两档。
- 密度切换不改变字号（字号恒定，只有尺寸与间距变化）。
- 导航侧栏不跟随密度（固定 29 行高）。

## 11. 禁止

- 用 `gap` 同时承担组内与组间（需要分组时用嵌套容器）。
- 用 `margin-top` 控制列表项间距（用 `gap` 或 `space-y`，便于统一）。
- 让不同模块的页面内边距不一致。
- 通过放大 `padding` 让控件"看起来更高级"（改高度阶梯，不改内边距乱填）。
