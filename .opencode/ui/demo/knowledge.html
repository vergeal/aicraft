接入方式

知识库以本地 MCP 服务器的方式接入。项目开启后，知识智能体会在需要时检索这里的正文，不会把全文塞进主对话。

opencode mcp add knowledge

可检索的内容

  • Markdown、纯文本与代码文件按原文索引；
  • 表格与演示文稿会先转成 Markdown，再建立索引；
  • 重复与高度相似的文件在导入时被跳过。

生效范围

只有被项目显式开启的知识库才参与检索。关闭后，已建立的索引保留，但不再返回给模型。

组件分层

基础组件只负责渲染，不读取全局状态；业务组件可以组合基础组件，并接收来自路由的数据。

  • 基础组件：按钮、输入、图标；
  • 业务组件：会话列表、项目树；
  • 页面：只负责布局与数据装配。

命名

组件文件名使用短横线分隔；对外导出的组件名使用大驼峰。不要用缩写表达业务含义。
