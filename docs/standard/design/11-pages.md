# 11 · 页面模板

每个页面只允许一个视线落点。落点由尺寸、位置、留白共同决定，不能靠颜色抢。

## 1. 新会话 / 首页

```
                 （窗口内容列 720 居中）
        [品牌 mark 28]（可选）
        从一个想法开始。        28/36/600
        描述你的目标…           14/22/次色
        ┌──────────────────────────────┐
        │ composer 720×176  圆角 24     │
        │ 输入区                        │
        │ [附件][工具][模式]      [模型][发送]│
        └──────────────────────────────┘
        或者，从一个具体场景开始   12/500/弱色
        ┌────────────┐ ┌────────────┐
        │ 卡片 354×84 │ │ 卡片 354×84 │
        └────────────┘ └────────────┘
        ┌────────────┐ ┌────────────┐
        │ 卡片 354×84 │ │ 卡片 354×84 │
        └────────────┘ └────────────┘
        ⌘K 命令面板 · ⌘N 新会话      11/弱色
```

| 项 | 值 |
| --- | --- |
| 内容列 | 720 |
| 上下留白 | 40（居中，不贴顶） |
| 标题 | 28 / 36 / 600 / -0.02em |
| 副标题 | 14 / 22 / 次色，上 10 |
| 标题组 ↔ composer | 32 |
| composer | 720×176，圆角 24 |
| composer ↔ 场景 | 28 |
| 场景标题 | 12 / 18 / 500 / 弱色，下 12 |
| 卡片 | 354×84，圆角 12，间距 12 / 10 |
| 场景 ↔ 页脚 | 20 |
| 页脚 | 11 / 16 / 弱色 |

规则：

- 背景只有一束极弱环境光（浅色 85% 白、深色 3.5% 白，椭圆 520×300），不做网格 / 粒子。
- 首屏入场 550ms 内完成：标题 80ms、副标题 130ms、composer 200ms、卡片两行 320/380ms、页脚 450ms。
- 场景卡最多 4 个，2×2；点击只填入模板并聚焦，不直接发送。
- 发送后同一工作区连续过渡到会话态，不重建 composer。

## 2. 列表页

```
页面头：标题 20/600            [+ 新建]（primary 32）
        说明 13/次色
筛选行：分段控件 28 | 搜索 240 | 视图切换
─────────────────────────────────────
列表容器（820）
  行 36–44：主文字 13 · 次信息 12 · 行尾操作
  行之间 1px 分隔（弱）
─────────────────────────────────────
分页 / 计数（11/弱色，居中）
```

- 列表行不加卡片，用分隔线。
- hover 整行 4% 覆盖；选中用 `bg-layer-02` + 左缘 2px。
- 批量操作出现时改用浮动工具条（底部居中，Z2）。
- 空列表显示空状态，不显示表头。

## 3. 详情页

```
页面头：返回 | 标题 20/600 | 元信息 12 | [操作]
─────────────────────────────────────
主内容（会话 650 / 文档 760 / 看板 820）
  分组标题 + 内容
─────────────────────────────────────
右侧面板（可选，320–560）：属性 / 活动 / 预览
```

- 标题与元信息在同一行或紧邻两行，元信息不超过 3 项。
- 主操作放页面头右侧，次要操作收进 `…` 菜单。
- 详情的编辑通过抽屉或独立编辑页，不在详情内联编辑长字段。

## 4. 设置页

见 [10 表单 §10](10-forms.md#10-设置页)。补充：

- 设置页左侧可加二级导航（宽 180–200），不与主导航列混用。
- 设置内容列 760，居中于工作区。
- 分组之间 32，组内行 48。

## 5. 新建 / 编辑页

见 [10 表单](10-forms.md)。补充页面级要求：

- 内容列：新增 480（单列）/ 640（双列）；编辑同宽，保证切换不跳。
- 页面头不带说明时可缩到 48 高。
- 底部操作条只在有显式保存时出现；自动保存页面不出现。

## 6. 空状态

| 场景 | 结构 |
| --- | --- |
| 首次进入（首页） | 品牌 mark → 标题 → 说明 → composer → 场景卡 |
| 列表为空 | 图标 24 → 标题 18 → 说明 14 → 主操作 |
| 搜索无结果 | 图标 → "没有找到「关键词」" → 清除筛选 |
| 权限不足 | 图标 → 原因 → 申请 / 切换账号 |

- 首次进入的空状态是产品门面，允许品牌表达；其他空状态保持中性。
- 空状态高度至少 240，垂直居中于内容区。

## 7. 加载态

| 时长 | 表现 |
| --- | --- |
| < 150ms | 不显示任何加载指示 |
| 150–400ms | 局部 spinner（16px） |
| > 400ms | 骨架屏，结构与真实内容一致 |
| 无法预估 | 骨架 + 说明文字（"正在读取 12 个文件…"） |

- 骨架块与真实内容同高，避免加载完成后跳动。
- 列表骨架 3–5 行；详情骨架按区块。

## 8. 错误态

```
图标 24（危险色或弱色）
标题 18/600：一句话说清发生了什么
说明 14/次色：可能原因
[重试]（primary 32）  [查看详情]（ghost）
```

- 不显示堆栈、错误码放"查看详情"里。
- 网络错误提供重试；权限错误提供切换账号；数据不存在提供返回。
- 整页错误居中，局部错误内嵌在对应区块。

## 9. 页面切换

| 切换 | 动效 |
| --- | --- |
| 同级页面 | 内容淡入 160ms，标题不重建 |
| 进入详情 | 内容淡入 + 8px 上移，180ms |
| 打开抽屉 | 220ms，`translateX(12px) + opacity` |
| 打开弹窗 | 180ms，`opacity + scale(.98)` |
| 返回 | 反向 160ms，不做整页滑动 |

页面切换期间，顶栏、侧栏、滚动位置保持不变。

## 10. 每页必查

1. 视线落点是否唯一？
2. 内容列宽是否按页型？
3. 空 / 载 / 错三态是否都设计了？
4. 1440 / 1280 / 1024 下是否都成立？
5. 页面切换时是否只有内容在动？
