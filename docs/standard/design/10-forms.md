# 10 · 表单、新增与编辑

## 1. 三种表单形态

先选形态，再排字段。

| 形态 | 使用条件 | 承载 |
| --- | --- | --- |
| 页内表单 | 设置、筛选、分组配置 | 页面区块 |
| 独立页面 | 字段 ≥ 4，或需要返回栈 | 内容列 480 / 640 |
| 抽屉表单 | 边看边改（重命名、属性、分支） | 右侧抽屉 |
| 弹窗表单 | 字段 ≤ 3，且必须处理完才能继续 | 480 弹窗 |

字段 ≥ 4 时禁止用弹窗。删除确认不算表单，用弹窗。

## 2. 表单页骨架

```
页面头（上 32 / 下 20）
  标题 20/28/600 · 说明 13/22/次色
  右侧：次要操作（ghost）
────────────────────────────────
内容列 480（单列）/ 640（双列），居中
  分组 1
    分组标题 12/500/弱色，下 12
    字段 …（字段间 20）
  分组之间 32
────────────────────────────────
底部操作条 56（吸底，可省略）
  左：危险操作（编辑态）
  右：[取消] [保存]
```

- 页面头与底部操作条固定在内容列宽度内对齐，不横贯窗口。
- 底部操作条使用画布底 + 顶部 0.5px 分隔，不悬浮、不加阴影。
- 表单在视口内不出现第二个滚动条：只有内容区滚动。

## 3. 字段结构

```
标签 13/500/主文字        [必填 *]（右对齐或标签后 2px）
控件 28（表单页 32）
帮助文字 12/18/次色（可选）
错误文字 12/18/危险色 + 图标（仅在出错时出现）
```

规则：

1. 标签在上、控件在下。**不允许左标签右控件**（在 480 列宽下会导致控件宽度不一致）。
2. 标签与控件间距 6；控件与帮助 6；帮助与错误不同时出现。
3. 必填标记用文字星号 `*`，悬停 Tooltip 说明"必填"；非必填不写"可选"（默认即非必填）。
4. 标签不使用 placeholder 代替。
5. 一行内字段高度必须一致。

## 4. 字段尺寸

| 类型 | 宽 | 高 |
| --- | --- | --- |
| 文本 / 数字 | 100%（最大 420） | 28 / 32 |
| 短文本（姓名、编号） | 240 | 28 / 32 |
| 下拉 | 100%（最大 420） | 28 / 32 |
| 多行文本 | 100% | 最小 88，最大 240 |
| 开关 | 内容宽 | 24×16 |
| 单选组 | 内容宽 | 选项行 28 |

窄字段必须显式设宽，不允许用 `flex: 1` 让它们随机拉伸。

## 5. 单列与双列

- 默认单列。
- 只有天然成对、且各自不超过 240 宽的字段才双列（起止日期、宽高、姓/名、城市/邮编）。
- 双列使用 `grid-template-columns: repeat(2, minmax(0, 1fr)); column-gap: 20px`。
- 双列区内的错误文字不能撑破列宽（`min-width: 0`）。
- 窗口 < 900px 时双列退化单列。

## 6. 校验

| 时机 | 行为 |
| --- | --- |
| 输入中 | 不提示错误（除实时计数、可用性检查） |
| 失焦 | 校验该字段，错误显示在字段下方 |
| 提交 | 校验全部，滚动并聚焦第一个错误 |
| 服务端失败 | 显示在对应字段；无对应字段时显示在表单顶部 |

规则：

- 错误文案写原因 + 修法："名称需 2–32 个字符"，不写"输入有误"。
- 错误只显示一次，不重复堆叠。
- 字段错误时边框变危险色，但**同时**必须有文字说明。
- 修正后错误立即消失（下一次输入时）。

## 7. 保存与取消

| 模式 | 适用 | 行为 |
| --- | --- | --- |
| 显式保存 | 新增、批量编辑 | 底部操作条 [取消] [保存]，保存后留在页面并 Toast |
| 自动保存 | 设置项、开关、单字段 | 变更即保存，短暂显示"已保存" |
| 即时生效 | 筛选、视图切换 | 不保存，无确认 |

规则：

1. 主操作文案是动词："创建项目""保存更改"，不写"确定"。
2. 保存中按钮进入 loading 并禁用，防重复提交。
3. 保存失败保留用户输入，错误显示在表单顶部与对应字段。
4. 有未保存修改时，关闭页面需确认（弹窗，"放弃修改 / 继续编辑"）。
5. 自动保存的表单不出现底部操作条。

## 8. 新增页 vs 编辑页

| 项 | 新增 | 编辑 |
| --- | --- | --- |
| 标题 | "新建 X" | "X 设置" 或对象名 |
| 字段 | 空 / 默认值 | 预填当前值 |
| 主操作 | 创建 | 保存更改 |
| 取消 | 返回列表 | 返回详情 |
| 危险区 | 无 | 页面最底部，单独分组 |
| 脏检测 | 有内容即脏 | 与初始值比较 |
| 保存后 | 跳转到详情 | 留在原页 |

新增页在字段少时可以只保留一个主按钮（无取消），返回走窗口返回。

## 9. 危险操作

- 放在页面最底部，与主内容间隔 32，上方 1px 分隔线。
- 分组标题"危险操作"，说明写明后果（"删除后无法恢复，关联的 N 个会话将被移除"）。
- 按钮用危险变体（描边或危险底），不使用 primary。
- 必须二次确认：弹窗 + 输入对象名（仅不可恢复且影响面大时）。
- 确认按钮文案写动作："删除项目"，不用"确定"。

## 10. 设置页

设置不是表单页：它是"分组列表 + 行内控件"。

```
分组（12/500/弱色）
  ┌ 行 48：标签 + 说明（左） 控件（右）┐
  └ 行 48：…                          ┘
分组之间 32
```

- 行高 48；标签 13/500，说明 12/次色。
- 控件右对齐，宽度固定（输入 200–280，开关内容宽）。
- 分组用连续表面，不逐行加卡片。
- 保存即时生效，行尾可短暂显示"已保存"。

## 11. 表单文案

| 位置 | 规则 |
| --- | --- |
| 标题 | 动词短语，≤ 12 字 |
| 说明 | 一句话说清用途，≤ 40 字 |
| 标签 | 名词，≤ 8 字 |
| 帮助 | 补充规则（格式、限制），≤ 40 字 |
| 错误 | 原因 + 修法，≤ 40 字 |
| 主按钮 | 动词 + 对象，≤ 6 字 |

## 12. 禁止

- 弹窗里放超过 3 个字段。
- 用 placeholder 当标签。
- 校验只在提交时发生。
- 保存按钮在没有修改时仍可点（应禁用或隐藏脏状态提示）。
- 离开页面静默丢弃修改。
- 表单里出现两个 primary 按钮。
- 危险操作与保存并列在同一行。
- 用红色文字表达"必填"。
