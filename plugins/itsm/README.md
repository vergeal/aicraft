# IT 工单

在桌面客户端里把长虹 ITSM 的表单填好，提交前由你逐项确认。插件用 Electron 内嵌浏览器驱动门户，不依赖本机 Chrome 或 Python，也不保存账号密码。

## 入口

- 左侧一级导航「IT 工单」，或命令面板里的「新建工单」。
- **设置 → IT 工单** 管理账号、门户地址和记住答案的偏好。
- 插件页顶部页签切换「服务项 / 历史 / 模板 / 设置」。

## 工作方式

1. 选一个服务项，向导逐题提问；答案可记住，下一轮预填。
2. 每个 OA 账号有自己的浏览器分区（`persist:itsm-<accountId>`），首次可导入本机 Chrome 里的 `.changhong.com` cookie，失败就开内嵌窗口手动登录。
3. 发版类工单的标题、发布方案、回退方案由插件内的会话调模型起草，你确认后才用。
4. 提交边界：堡垒机第一页可以「确认并提交第一页」（二次确认），第二页只填不提交；发版永远停在提交前。

## 服务目录

登录后从门户拉取服务目录并缓存，之后在本地搜索和分组；顶部刷新按钮重新同步。

## 模板

内置模板对应三条常用流程，可改名、调问题顺序、增删问题，但不能改动内置步骤。自定义模板保存在本地。

## 账号与隐私

- cookie 只留在各自的浏览器分区里，不会导出。
- 不保存密码，也不写入系统钥匙串。
- 与门户的交互只在你自己点击「确认并提交」后才发生。

## 构建与分发

```sh
bun run build   # 产出 dist
bun run pack    # 产出 ~/.distribution/plugins/changhong.itsm/<version>/*.craf
```
