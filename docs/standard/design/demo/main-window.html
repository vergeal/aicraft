重新打开会话时，滚动条总是跳回顶部。能修一下吗？

原因在恢复时机：scrollTop 在 ref 阶段就写了，那时元素还没进文档，高度为 0。挪到 onMount 之后，并用记录的锚点行校正一次。

screen-layout.ts 
// 等列表量出真实高度后再落位
  onMount(() => {
    requestAnimationFrame(() => restore(anchor))
  })

现在重开会话，位置会落回你上次离开的那一行。
