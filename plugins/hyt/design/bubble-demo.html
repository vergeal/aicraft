聊天气泡样式 · 提案

同一套圆角（12px）与内边距贯穿所有类型；图片、文件、链接卡把内边距让给内容，用气泡自身的圆角裁切。

  1. 去掉切角：气泡四角同为 12px。自己 / 他人的区分交给底色与对齐，不靠一个被削掉的角。
  2. 图片满出血：图片贴到气泡边缘，带说明时说明单独一条压在下面，按原比例显示，最高 320px。
  3. 文件改一行：32px 类型标记 + 文件名 + 大小，去掉气泡内部那条分隔线；表格类给一点绿，其余中性色。
  4. 链接有样子：正文里的地址是浅下划线链接，整条只有一个地址时升级成链接卡（域名 + 完整地址）。
  5. 语音 / 视频 / 通话、合并转发收进同一族：同底色、同圆角，悬停才加深。
  6. 读不到的类型不再用虚线框假装成消息，退成一行灰色说明。
  7. 行距两档：换人或隔了 5 分钟以上 22px，同一个人连续发言 14px。

行距两档

换人或隔了 5 分钟以上 22px，同一个人连续发言 14px。复制行改成绝对定位压在间隙里，不再用一段透明高度撑开行距。

一套几何

气泡 12px、内部块 8px、类型标记 32px。所有类型都落在这三个数上，不再各写一套内边距。

内边距让给内容

图片 / 文件 / 链接卡用 bubble--tight：气泡 padding 归零，圆角负责裁切，说明文字单独一条压在下面。

颜色只做轻提示

只有表格类文件标记带一点绿（复用 --face-a-*），其余全是中性底；红色只留给 @、未读与撤回。

链接可点

正文里的地址渲染成浅下划线链接，点击走 ctx.system.openExternal；整条只有一个地址时升级成卡片。

消息已读回执

自己发出的消息，气泡下方报「N 人已读」，点开看谁读了、谁没读。回执是虹云通客户端逐条上报的，插件只做聚合与展示，不自己编状态。

  1. 入口只有一行：气泡右下一行小字，群聊写「3 人已读 · 2 人未读」，全部读完只留「5 人已读」；单聊写「已读 / 未读」。
  2. 弹窗两段：未读在上、已读在下，都带头像与名字；已读区带时间，未读区只写「未读」。成员多时给搜索。
  3. 谁算进去：已读人数来自回执；未读 = 群成员 − 已读 − 自己。退群的人从两段里同时消失，不会一直挂在未读。
  4. 实时：弹窗开着时回执进来就往上加，不关不重排；关掉不改任何状态。
  5. 拿不到就说拿不到：历史消息或离线期间没收到的回执，显示「已读信息暂不可用」，不显示 0 人。

只有自己的消息有回执

别人发来的消息不挂回执：我们知道的是「自己有没有读」，不是「别人读了别人什么」。发给自己的附件、系统提示同样不挂。

人数怎么算

已读人数取回执聚合；未读 = 群成员 − 已读 − 自己。成员退群后从两段同时移除，未读数跟着降，不会留一个永远清不掉的尾巴。

一行文案的两种写法

还有未读时写「3 人已读 · 2 人未读」，全部读完只留「5 人已读」。单聊不用人数，直接写「已读 / 未读」。

实时增量

弹窗打开期间收到回执只往上加、不动已渲染的行；关闭弹窗不改变任何状态，也不再把这条标成什么。

拿不到就说拿不到

历史消息、离线期间没收到的回执，显示「已读信息暂不可用」并可重试，绝不先显示 0 人再跳成 3 人。

不挂送达 / 已读双勾

气泡里不再叠一层「送达 / 已读」图标：群聊的回执本来就是人数事实，双勾只会把同一件事说得更模糊。
