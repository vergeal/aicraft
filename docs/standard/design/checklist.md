# 落地检查清单

评审一份界面实现时逐条过。每条都有可判定的标准，不是"感觉对不对"。
**红线项（标 🔴）任一不过即需返工**，其余按比例记录。

## A. 色彩（5）

- [ ] 🔴 **A1 组件里没有十六进制色值。** 搜 `#[0-9a-f]{3,8}`，命中只允许出现在 token 定义文件。
- [ ] **A2 每个颜色都有深浅两值。** 单值 token 必须用 `light-dark()` 或两表同步。
- [ ] **A3 深色下边框/悬停透明度比浅色高 2–6 个百分点。**
- [ ] **A4 彩色底上的文字来自 `on-color` / `foreground` 类 token。** 不写 `#fff`。
- [ ] **A5 主操作按钮是黑/白填充，不是品牌色。**

## B. 排版（5）

- [ ] 🔴 **B1 行高显式声明。** 全仓 `line-height: normal` 应为 0 处。
- [ ] **B2 UI 字号 11–16px，正文 14px。** 只有空状态/引导页允许 20px+。
- [ ] **B3 字重最多 400/500/600/700。** 用 510/590 必须定义 fallback。
- [ ] **B4 中文正文行高 ≥ 1.55。**
- [ ] **B5 中文最小 12px。** 11px 只用于英文或纯数字。

## C. 间距与尺寸（4）

- [ ] **C1 间距全是 2 的倍数，主节奏 4/8/12/16/20/24。** 不出现 5/7/9/11/13/15。
- [ ] **C2 控件高度落在 20/24/28/32/36/40/48。** 同屏相邻差 ≤ 一档。
- [ ] 🔴 **C3 单行文本有 `min-width: 0` + 截断。** 侧栏、表格、卡片标题都要查。
- [ ] **C4 正文列宽有上限（700–900px）。** 全屏拉伸视为缺陷。

## D. 圆角与描边（4）

- [ ] **D1 圆角只用 8/12/16/20/28/999。**
- [ ] **D2 控件边框 0.5px + inset stroke，不用 1px border。** 表格分隔线除外。
- [ ] **D3 0.5px 用 box-shadow/outline 绘制，不用 border。**
- [ ] **D4 阴影 alpha ≤ 0.12（浅色）。**

## E. 组件状态（4）

- [ ] 🔴 **E1 每个交互组件都有 hover / active / disabled / focus 四态。**
- [ ] 🔴 **E2 状态样式挂语义属性（`aria-checked` / `data-state`），不是 `.is-active`。**
- [ ] **E3 disabled 用 `opacity: .4–.5`，不改颜色。**
- [ ] **E4 点击热区 ≥ 24×24。**

## F. 动效（3）

- [ ] **F1 时长 100–300ms，默认 150ms。**
- [ ] **F2 只过渡 `transform` / `opacity` / 颜色。** `transition:.*(height|width|box-shadow)` 应为 0。
- [ ] **F3 reduced-motion 关闭装饰动画，保留状态反馈。**

## G. 主题（3）

- [ ] 🔴 **G1 首屏内联背景色、字号、字体族、`color-scheme`。**
- [ ] **G2 JS 写入 `body.style` 的 token 有记录并能清除。**
- [ ] **G3 `theme-color` 从计算样式取。**

## H. 可访问性（6）

- [ ] **H1 焦点环用 `:focus-visible`，宽 ≥ 1px。** 密集区域可降 1px，不可为 0。
- [ ] **H2 关闭对话框归还焦点；删除当前项后焦点移到相邻项。**
- [ ] **H3 图标按钮有可读名；装饰图标 `aria-hidden`。**
- [ ] **H4 正文对比度 ≥ 4.5:1，边框/图标 ≥ 3:1。**
- [ ] **H5 浮层支持 `Esc`，一组控件用 roving tabindex。**
- [ ] **H6 200% 缩放无横向滚动、无文字裁切。**

## I. 图标（4）

- [ ] **I1 统一 24 网格、2px 描边；跨网格按 `网格/12` 换算。**
- [ ] **I2 图标命名不含尺寸，尺寸走 prop。**
- [ ] **I3 全产品只有一种描边风格，第三方图标已对齐端点与线宽。**
- [ ] **I4 图标只用 `currentColor`，状态色由成套状态图标承担。**

## J. 表格（4）

- [ ] **J1 字号 13、行高 22（随字号轴缩放）、表头 500。**
- [ ] **J2 只用横向 0.5px 分隔线，不叠加斑马纹。**
- [ ] **J3 数字列右对齐并开 `tabular-nums`。**
- [ ] **J4 空值统一 `—`；"空表"与"筛选无结果"文案不同。**

## K. 表单（4）

- [ ] **K1 字段 = 标签 + 控件 + 辅助/错误，纵向 gap 6。**
- [ ] **K2 控件高 32、内距 6 12、边框 0.5px、圆角 12，全表单统一。**
- [ ] **K3 失焦与提交时校验；报错后实时复核，改对即清除。**
- [ ] **K4 一页只用一种保存策略；未保存离开必须确认。**

## L. 导航（3）

- [ ] **L1 三层导航视觉权重递减。**
- [ ] **L2 侧栏折叠保留图标与 56px 宽度，不用 `display: none`。**
- [ ] **L3 选中态有形状信号（竖条/下划线/滑块），不只靠颜色。**

## M. 图表（3）

- [ ] **M1 序列色只用语义 token，深浅同值；超 6 类改图形。**
- [ ] **M2 颜色不是唯一编码，必须叠加形状或直接标注。**
- [ ] **M3 每张图有数据表替代与一句话结论。**

## N. 国际化（4）

- [ ] **N1 字体栈拉丁在前、CJK 在后；代码字体不含裸 `monospace`。**
- [ ] **N2 无全局 `word-break: break-all`。**
- [ ] **N3 按钮/导航按内容撑开，等宽场景用 `flex: 1`。**
- [ ] **N4 中文语境用全角标点，行首无禁则字符。**

## O. 密度（3）

- [ ] **O1 只有两档且按区域固定，不提供用户切换。**
- [ ] **O2 紧凑档只压留白与圆角，字号不变。**
- [ ] **O3 紧凑档热区仍 ≥ 24×24，焦点环仍可见。**

## P. 桌面端（4）

- [ ] **P1 拖拽区只在标题栏，子元素统一 `no-drag`。**
- [ ] **P2 平台差异走 `data-platform`，无散落 UA 判断。**
- [ ] **P3 滚动条不占布局（`scrollbar-gutter: stable`）。**
- [ ] **P4 最小窗口 720×560，低于则转单栏。**

## Q. 治理（3）

- [ ] **Q1 新增 token 通过四问（已有替代？双主题有值？名字自明？可删除？）。**
- [ ] **Q2 删除/重命名 token 走 major 版本 + 迁移指南。**
- [ ] **Q3 文档与代码一致；不一致时已按代码修正文档。**

---

**统计**：共 66 条，红线 6 条（A1、B1、C3、E1、E2、G1）。
红线全过才可合入；其余按项记录，连续两个版本未改善的项升级为红线。
